## Рішення залишити

Нові бібліотеки `categories/*` уже розкладено за ролями (`tables/`, `cards/`, `content/`, `editor/`, `hooks/`, `errors/`), найбільший файл — 139 рядків панелі редактора. `core/shell/.../admin-sidebar.tsx` (180), `orders.api.ts` і `orders.mapper.ts` (~150) мають одну цілісну роль. `theme/components.ts` — єдиний конфіг перевизначень MUI. Кількість рядків — спостереження, а не правило поділу.

## Перевірка й межі

`npx nx run-many -t lint,typecheck` для змінених admin-проєктів і `npx nx affected -t lint,typecheck`: exit 0. Vitest: `admin-shared-ui` 23, `admin-products-ui` 7, `admin-products-feature` 17, `admin-orders-ui` 19, `admin-orders-feature` 17 — усі пройшли. `npm run docs:check`. Браузерні, E2E, production build і повний прогін не запускалися.
