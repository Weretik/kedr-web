# Готовність до постачання

Для зміненого scope записати фактичні докази; незапущений повний прогін поза
прямим запитом користувача не є перешкодою.

- [ ] Усі in-scope `SC-*` перевірено, `TS-*`/`EN-*` закрито.
- [ ] Контракти, runtime validation, UI та feature docs узгоджено.
- [ ] Запущено лише мінімальні перевірки змінених частин за [правилами обсягу](../../../../../standards/shared/testing-rules.md#verification-scope-during-implementation); повний прогін і production build — лише за прямим запитом.
- [ ] Тему, локаль і адаптивність звірено за кодом; browser journey, ручний keyboard/layout огляд або E2E не запускалися без окремого запитання й прямого дозволу користувача.
- [ ] Traceability містить test paths, результати та залишкові ризики.
