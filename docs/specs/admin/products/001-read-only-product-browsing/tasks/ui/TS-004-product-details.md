# TS-004 — Read-only картка товару

**Covers:** SC-004, SC-005, SC-007, SC-010. **Depends on:** TS-002. **Статус:** реалізовано; автоматичні тести зміненої картки виконано, browser-приймання не запускали.

**Шляхи:** `libs/admin/products/feature/src/pages/product-details-page.tsx`, компоненти в `libs/admin/products/ui/src/` за потреби.

**Робота:** Admin detail за slug показує одну назву в головному блоці, українську й російську назви, таблицю основних відомостей без category slug і лише істинні різнокольорові ознаки. На широкому екрані порядок блоків — фото, основна інформація, схема справа; на вужчих екранах він зберігається. Зображення безпосередньо клікабельні й збільшуються через MUI Dialog, невдалу схему приховано. Презентаційні картки, таблицю й Dialog винести до `ui/src/components`, а в `feature` лишити route/API та стани завантаження. Виразна кнопка публічного товару є лише за `exportToSite=true` і slug; кнопка папки сховища — для кожного товару в головному блоці, окремої кнопки JPG немає. Повернення — текстове посилання зі стрілкою без спільних breadcrumbs. Зберегти loading/404/error/invalid slug, back-контекст, доступність, телефон/планшет і обидві теми. Без edit/delete/cart.

**Рівень:** component. **Докази:** тести зміненої картки й Dialog; тему та breakpoints звірити за кодом, браузер лише за окремим дозволом. **Checkpoint:** картка показує тільки дані підтвердженого Admin detail API.
