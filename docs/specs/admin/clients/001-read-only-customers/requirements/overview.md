# Клієнти — межі та результат

## Мета

Як користувач Admin, я хочу переглядати список клієнтів і відкривати доступну інформацію про кожного, щоб знаходити їхні контактні та цінові дані без зміни записів.

## У межах

- Пункт меню «Клієнти» відкриває серверно пагінований список тільки активних клієнтів.
- Доступний перехід із кожного рядка до read-only картки та повернення зі збереженням сторінки списку.
- У списку: ім'я, телефон за наявності й ідентифікатор. У картці: ім'я, ідентифікатор, телефон, email та цінові налаштування. Типи цін показуються назвами замість числових ID; кожна категорія — назвою разом з ID.
- MUI Data Grid надсилає одне поле пошуку до API; сервер шукає ID, ім'я й телефон у всій вибірці перед пагінацією і повертає кількість знайдених клієнтів. Фільтри колонок і керування сортуванням у UI відсутні.
- Loading, empty, error, invalid link, not found і доступний retry.

## Поза межами

Редагування, видалення, створення, замовлення, платежі, адреси, статуси, quota, аватари й експорт.

## Обмеження

Термін «повна інформація» означає всі поля погодженої операції деталей, а не довільний профіль із референсу. Нові nullable назви підтверджено в backend OpenAPI та синхронізованих frontend snapshot/generated types. Адмінська операція зараз anonymous у OpenAPI; production rollout залежить від політики backend доступу.
