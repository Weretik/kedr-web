# Customers — React and visual interaction

Visual basis: the provided Devias Kit Pro references for the customer list and card. Use their composition of menu, heading, rounded Card, compact table, and information blocks within the existing Admin theme. Do not carry over the reference's Active/Pending/Blocked tabs, avatars, quota, payments, billing, shipping, or notifications: Kedr API has no such data or filters.

- List: heading «Клієнти»; MUI Data Grid columns «Клієнт», «Телефон», “ID”, and «Дії»; one permanently visible `QuickFilterControl` in the table toolbar. The «Пошук клієнтів» field has a magnifying-glass icon inside the field on the left; there is no separate form or “Search” button. `filterModel.quickFilterValues` is controlled by feature and sends `searchTerm` to the API; `paginationMode="server"`, and `rowCount` matches `totalRecords` after search. Sorting and column filters are disabled. «Дії» contains an eye icon with the tooltip «Переглянути клієнта» and an accessible name. All columns are reachable through horizontal scrolling on narrow screens. Built-in labels and controls are localized in Ukrainian through the Admin theme.
- Keep search and page in feature and the URL; debounce text input, reset page to 1, and restore search after returning from details. Do not show a separate search form or a caption below the table with the count and an explanation of server behavior.
- Details: retain the MUI Link with arrow, «Назад до клієнтів», and the «Деталі клієнта» heading. Below it, place three separate compact MUI Cards: basic information (name once and ID), contacts (phone and email), and price types (default and per-category). Use labeled value pairs without tables, compact spacing, and current Admin theme colors. Use one column on phones, two on tablets, and three on wide screens. Replace numeric price-type IDs with confirmed backend names; show each category by name and ID. Render `null` names as «Назва недоступна», not as a price-type ID. Show «Не вказано» for `phone=null`.
- Loading/empty/error/not-found states have stable dimensions and short Ukrainian messages. Check focus, accessible names, keyboard use, 320 px width, and desktop.

Checks: only automated focused/component tests for the changed feature's states and navigation. Verify theme, locale, and breakpoint wiring in code. A browser journey from list to card and back requires a separate question and the user's direct approval for that specific check.
