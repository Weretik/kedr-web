# TS-003 — Картка клієнта

**Covers:** SC-003, SC-004, SC-006. **Depends on:** TS-001. **Статус:** planned.

**Шляхи:** `libs/admin/clients/feature/src/pages/customer-details-page.tsx` (новий), `libs/admin/clients/ui/src/components/` за потреби.

**Робота:** відобразити всі й лише поля `getAdminCustomerById`, nullable phone, масив category/price IDs, loading/invalid ID/404/error. Заголовок «Деталі клієнта» не повторює ім'я; три компактні Card без таблиць показують основну інформацію (ім'я й ID), контакти та типи цін під окремими заголовками. Повернення оформити MUI Link зі стрілкою за чинним зразком деталей товару та зберегти контекст через контракт TS-004. Забезпечити повноту й читабельність полів на телефоні та планшеті в світлій і темній схемах Admin. Завершити перевіркою цілісності файлів і розділити незалежні ролі за потреби.

**Рівень:** component. **Докази:** записати тест/Red/Green/Regression і keyboard QA. **Checkpoint:** картка доступна без редагування й вигаданих секцій.
