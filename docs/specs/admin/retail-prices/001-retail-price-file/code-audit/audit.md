# Feature audit: Admin «Завантажити роздрібні ціни»

- **Scope:** `libs/admin/retail-prices/{data-access,feature}`, `libs/admin/products/feature` (`listActions` slot), `libs/admin/shared/api-client` (tag), `libs/admin/work/model` (activity label), `apps/admin/src/app/router/app-router.tsx`, `apps/stack-e2e` (fixture and journey), the contract snapshot.
- **Date:** 2026-11-26, after implementation (TS-004), by skill `frontend-code-audit`.
- **Sources:** [code organization](../../../../../standards/shared/code-organization.md), [list and detail pages](../../../../../standards/admin/list-detail-pages.md), [idempotency rules](../../../../../standards/shared/idempotency-rules.md), [contracts](../../../../../contracts/README.md), KedrStore `docs/sdd/architecture/overview/quality-targets.md`, feature review list of the architecture toolkit.
- **Method:** static review of every changed file, `npm run architecture:structure`, `npm run architecture:boundaries`, `npm run docs:check`, lint, typecheck and focused tests of every changed project. No browser or E2E run (not permitted without the owner's separate consent); the new E2E journey runs in CI.

## Step 0: quality targets

The client depends on the API write P95 ≤ 2 s from the backend quality targets; the import is a heavy operation of about 1 600 rows, which the backend spec allows up to 10 s (its latency is not measured yet, KedrStore AF-05). The status is one small `GET`. The project still has no target for Admin screen load time (AF-001).
