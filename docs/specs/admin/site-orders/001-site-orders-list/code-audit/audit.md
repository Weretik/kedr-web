# Feature audit: Admin «Замовлення з сайту»

- **Scope:** `libs/admin/site-orders/{model,data-access,ui,feature}`, the menu item in `libs/admin/core/shell/src/navigation/navigation-groups.tsx`, the routes in `apps/admin/src/app/router/app-router.tsx`, the cache tag in `libs/admin/shared/api-client/src/rtk-query/base-api.ts`.
- **Date:** 2026-11-24, after implementation (TS-006).
- **Sources:** [code organization](../../../../../standards/shared/code-organization.md), [list and detail pages](../../../../../standards/admin/list-detail-pages.md), [idempotency rules](../../../../../standards/shared/idempotency-rules.md), [contracts](../../../../../contracts/README.md), KedrStore `docs/sdd/architecture/overview/quality-targets.md`.
- **Method:** static review of every file in scope, `npm run architecture:structure`, `npm run architecture:boundaries`, lint, typecheck and focused tests of the changed projects. No browser or E2E (not permitted without the owner's separate consent).

## Step 0: quality targets

The client depends on the API read P95 ≤ 1 s (confirmed, current 328 ms) and write P95 ≤ 2 s (confirmed, current 1 159 ms) from the backend quality targets. The list and the detail page make one `GET` each; the resend is one `POST`. The project has no target for Admin screen load time (AF-001).
