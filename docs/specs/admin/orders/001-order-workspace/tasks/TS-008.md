# TS-008 — Пошук і діапазон дат у списках

- **Covers/Enables:** R-012–R-013; SC-010
- **Depends on:** EN-002 для backend date contract і generated snapshot
- **Фактичні шляхи:** `libs/admin/orders/feature/src/components/order-tables.tsx`, `libs/admin/orders/ui/src/tables/order-grid-toolbar.tsx`, `libs/admin/orders/data-access/src/api/orders.api.ts`, `libs/admin/orders/model/src/orders-model.ts`.
- **Реалізація:** дві вкладки мають окремі URL ключі дат; валідний діапазон додається до server query, зміна скидає сторінку, невалідний або обернений діапазон пропускає запит. Toolbar використовує MUI X QuickFilter і DatePicker.
- **Evidence:** `libs/admin/orders/feature/src/components/order-tables.spec.tsx` перевіряє параметри query і URL стан на 2026-10-22. Provider OpenAPI snapshot і generated types досі не містять `createdFrom`/`createdTo`; сумісність backend і межі `Europe/Kyiv` не доведені цим snapshot.
- **Checkpoint:** після оновлення provider contract виконати workflow `contracts:sync`, `contracts:generate`, `contracts:check` та закрити включні календарні межі `Europe/Kyiv`.
