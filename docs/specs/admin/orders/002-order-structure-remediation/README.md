- **Scope:** React Admin orders only; behavior and HTTP contracts remain unchanged.
- **Source:** [audit 001](../001-order-workspace/code-audit/audit.md), [organization rules](../../../../standards/admin/admin-code-organization.md), and [dependency boundaries](../../../../architecture/admin/structure/dependencies.md).

## Requirements and decisions

| Requirement                                     | Finding       | Task and target                                                                                                                                                                                                                                          | Verification                                                                                |
| ----------------------------------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| AR-001: page coordinates independent UI flows   | AF-001        | RM-001: `OrderTables` retains URL/table ownership; deletion moves to `feature/src/hooks/use-draft-deletion.ts` and `dialogs/draft-delete-dialog.tsx`.                                                                                                    | Tabs/URL and confirmed deletion using the current version.                                  |
| AR-002: submission and draft use separate flows | AF-002        | RM-002: `NewOrderPage` coordinates the quote; `use-save-draft` and `use-submit-order` manage separate mutations; forms and Dialog live in `ui/src/forms` and `dialogs`.                                                                                  | Retry with a new price, draft creation, and preservation of the current selection on error. |
| AR-003: mapper belongs to data-access           | AF-003        | RM-003: `mappers/orders.mapper.ts` remains private; `api/order-conflict.ts` exposes a domain conflict; the public barrel does not export the mapper.                                                                                                     | Mapper test and TypeScript boundary.                                                        |
| AR-004: directories have clear thematic roles   | AF-001–AF-003 | RM-004: UI is divided into `tables` (separate grid and toolbar), `details`, `forms`, and `dialogs`; data-access into `api` and `mappers`; feature into `pages`, `components`, `hooks`, `state`, and `dialogs` (separate delete and retry confirmations). | Search for old paths, check Markdown links and Nx boundaries.                               |

**Order:** RM-003 → RM-002; RM-001 is independent; RM-004 is performed with the moves. No new behavior is introduced. Rollback restores imports and files together; the database schema and OpenAPI do not change. The [implemented feature map](../../../../features/admin/orders.md) contains the current tree. AF statuses and verification results are tracked in audit 001 to avoid duplicating them here.
