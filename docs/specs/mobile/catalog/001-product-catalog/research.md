# Research: Mobile product catalog

| Question                  | Decision                                                                                                                                                                              | Rationale                                                                                                                                                       | Alternatives                                                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Main catalog presentation | React Native `FlatList` + single-column `ProductCard`                                                                                                                                 | `FlatList` provides a virtualized list, header/footer, refresh, scroll loading, and `numColumns` without a new native dependency.                               | MUI Data Grid is not intended for React Native; `ScrollView` renders the entire catalog; `SectionList` is only needed for actual sections. |
| Pagination UX             | `GET /api/admin/products` with `page`/`pageSize` and an explicit «Завантажити ще» action                                                                                              | `pagedInfo.pageNumber` and `totalPages` indicate whether another page exists; an explicit action is stable on mobile networks and easy to retry after an error. | Page-number controls take mobile space; client-side pagination requires loading the entire catalog.                                        |
| Search and filters        | Server-side `searchTerm` with debounce; Paper `Searchbar`, `Modal`/`Portal`, `Chip`, `Menu`                                                                                           | The contract provides search, boolean filters, category, price range, and sort. There is no filter-facets endpoint, so the UI cannot invent dynamic options.    | Local filtering is incomplete; a separate UI library violates the project standard.                                                        |
| Visual P3 flow            | Filter button opens Paper `Modal`/`Portal`; applied values appear as Chips; sort is selected from Paper `Menu`; category selector appears only after a valid data source is available | This is a compact mobile flow without a desktop table. Paper documents a controlled `Menu`, toggle/single-choice controls, and accessible labels.               | Always-visible desktop filter panels; an invented category list.                                                                           |
| Performance upgrade       | Start with `FlatList`; consider FlashList only after profiling on Galaxy A12                                                                                                          | A new dependency is not justified in the current scope. FlashList v2 requires the New Architecture.                                                             | Adding FlashList prematurely; Data Grid.                                                                                                   |

Sources: [React Native FlatList](https://reactnative.dev/docs/flatlist), [FlashList v2](https://shopify.github.io/flash-list/docs/v2-migration/), [React Native Paper Menu](https://callstack.github.io/react-native-paper/docs/guides/react-navigation), [React Native Paper toggle controls](https://callstack.github.io/react-native-paper/4.0/toggle-button.html), [React Native Paper RadioButton](https://callstack.github.io/react-native-paper/docs/components/RadioButton/RadioButtonAndroid/).
