# Research: Mobile product catalog

| Питання                        | Рішення                                                                                                                                                                        | Причина                                                                                                                                             | Альтернативи                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Основне представлення каталогу | React Native `FlatList` + одноколонкові `ProductCard`                                                                                                                          | `FlatList` дає virtualized list, header/footer, refresh, scroll loading і `numColumns` без нової native залежності.                                 | MUI Data Grid не призначений для React Native; `ScrollView` рендерить весь каталог; `SectionList` потрібен лише для реальних секцій. |
| Pagination UX                  | `GET /api/admin/products` з `page`/`pageSize` і явною дією «Завантажити ще»                                                                                                    | `pagedInfo.pageNumber` і `totalPages` визначають наявність наступної page; явна дія стабільна в mobile network і її легко повторити після error.    | Page-number controls займають mobile space; client-side pagination потребує завантаження всього каталогу.                            |
| Search і filters               | Server-side `searchTerm` з debounce; Paper `Searchbar`, `Modal`/`Portal`, `Chip`, `Menu`                                                                                       | Contract надає search, boolean filters, category, price range і sort. Filter-facets endpoint відсутній, тому UI не може вигадувати dynamic options. | Local filtering неповна; окрема UI library порушує project standard.                                                                 |
| Visual P3 flow                 | Filter button відкриває Paper `Modal`/`Portal`; applied values показуються Chips; sort обирається з Paper `Menu`; category selector з’являється лише після чинного data source | Це компактний mobile flow без desktop table. Paper документує керований `Menu`, toggle/single-choice controls та accessible labels.                 | Постійно відкриті desktop-панелі фільтрів; вигаданий список категорій.                                                               |
| Performance upgrade            | Почати з `FlatList`; розглянути FlashList лише після profiling на Galaxy A12                                                                                                   | У поточному scope нова залежність не виправдана. FlashList v2 потребує New Architecture.                                                            | Передчасне додавання FlashList; Data Grid.                                                                                           |

Sources: [React Native FlatList](https://reactnative.dev/docs/flatlist), [FlashList v2](https://shopify.github.io/flash-list/docs/v2-migration/), [React Native Paper Menu](https://callstack.github.io/react-native-paper/docs/guides/react-navigation), [React Native Paper toggle controls](https://callstack.github.io/react-native-paper/4.0/toggle-button.html), [React Native Paper RadioButton](https://callstack.github.io/react-native-paper/docs/components/RadioButton/RadioButtonAndroid/).
