# Requirements checklist: Mobile product catalog

- [x] CHK001 User stories мають пріоритет та independent test.
- [x] CHK002 Functional requirements конкретні, перевірювані та не суперечать одна одній.

- [x] CHK004 Success criteria вимірювані та не прив'язані до реалізації.
- [x] CHK005 Android/iOS/web припущення й зовнішні API залежності зафіксовані.
