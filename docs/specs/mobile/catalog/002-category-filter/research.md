# Research: Mobile catalog category selection

| Question                           | Decision                                                                          | Rationale                                                                                                                                   | Alternatives                                                                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Which options source to use        | `GET /api/categories` (`getAdminCategories`)                                      | Updated OpenAPI defines rows with `parentId`, `sortOrder`, and localized short names; this resolves blocker T021 from the previous feature. | Static list is forbidden; `GET /api/catalog/{lang}/categories` was not selected because the user requested the admin categories contract. |
| How to represent the flat response | Mapper builds `CatalogCategoryOption[]` from `parentId`, sorting siblings         | The UI already accepts a recursive category model, while the DTO stays in `data-access`.                                                    | Keep flat rows in the UI or change the selector to use the transport shape.                                                               |
| How to limit selector complexity   | Display at most 3 levels; exclude malformed rows without a crash                  | This is a constraint in the current P3 task; the API permits a recursive structure through `parentId`.                                      | Unbounded recursion without validation.                                                                                                   |
| Which name to display              | `shortNameUk`; `shortNameRu` only as fallback                                     | Ukrainian is the primary language of the mobile app at this stage.                                                                          | DTO `name` is not a localized short name.                                                                                                 |
| How to apply the selection         | Write only `categoryId` to the existing products query through reducer Apply flow | Products contract documents `categoryId`, and the reducer already resets the page when filters are applied.                                 | Local product filtering or sending both `categoryId` and `categorySlug`.                                                                  |

Open product decision: the backend owner must confirm mobile client access
to the administrative endpoint before production rollout.
