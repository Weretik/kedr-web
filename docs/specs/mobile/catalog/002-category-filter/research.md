# Research: Вибір категорії у mobile catalog

| Питання                             | Рішення                                                                    | Причина                                                                                                                                 | Альтернативи                                                                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Яке джерело options використовувати | `GET /api/categories` (`getAdminCategories`)                               | Оновлений OpenAPI визначає список rows з `parentId`, `sortOrder` і localized short names; це закриває blocker T021 попередньої feature. | Static list заборонений; `GET /api/catalog/{lang}/categories` не обрано для цієї задачі, бо user запросив admin categories contract. |
| Як подати flat response             | Mapper будує `CatalogCategoryOption[]` за `parentId`, сортуючи siblings    | UI вже приймає recursive category model, тоді як DTO не виходить із `data-access`.                                                      | Зберігати flat rows в UI або змінювати selector на transport shape.                                                                  |
| Як обмежити складність selector     | Відобразити щонайбільше 3 рівні; malformed rows виключити без crash        | Це обмеження в чинній P3 task; API дозволяє recursive структуру через `parentId`.                                                       | Необмежена рекурсія без валідації.                                                                                                   |
| Яку назву показувати                | `shortNameUk`; `shortNameRu` лише як fallback                              | Українська є основною мовою mobile застосунку на поточному етапі.                                                                       | DTO `name` не є локалізованою short name.                                                                                            |
| Як застосувати вибір                | Писати лише `categoryId` у існуючий product query через reducer Apply flow | Products contract документує `categoryId`, а reducer already скидає page при filters apply.                                             | Local product filtering або одночасне надсилання `categoryId` і `categorySlug`.                                                      |

Відкрите product-рішення: backend-власник повинен підтвердити доступ mobile client
до адміністративного endpoint до production rollout.
