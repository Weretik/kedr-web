# Дослідження: catalog discovery UI

| Питання                       | Рішення                                                                                                 | Evidence / reference                                                                                                                                                              | Відхилена альтернатива                                | Причина                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------- |
| Який SDD-шаблон?              | `mobile-feature` + додатковий `visual-spec.md`                                                          | Задача додає dependencies і persisted local state, не тільки стилі                                                                                                                | Лише `mobile-visual`                                  | Visual template не описує storage та dependency rollout достатньо повно         |
| Яку тему застосувати?         | Тільки поточні `mobileLightTheme` / `mobileDarkTheme`                                                   | `libs/mobile/core/shell/src/theme/app-theme.ts`                                                                                                                                   | Themes із двох прикладів                              | Користувач прямо заборонив змінювати власну корпоративну тему                   |
| Як взяти UX із прикладів?     | Взяти структуру: компактна шапка, окремі action controls, контрастні card surfaces, вертикальний список | `Ecommerce-mobile-template-main/src/screens/ShopScreen/*`, `.../ProductCard/*`; `react-native-expo-shop-template-main/src/components/ProductsListVertical.tsx`, `ProductCard.tsx` | Копіювання коду/токенів/навігації                     | Приклади належать іншим застосункам та мають інші state/theme boundaries        |
| Як показувати довгий список?  | `@shopify/flash-list` у `CatalogList`                                                                   | Схвалений [каталог UI можливостей](../../../../architecture/mobile/ui-capabilities.md)                                                                                            | Лишити `FlatList`                                     | Архітектурне рішення передбачає FlashList для нових/перероблених довгих списків |
| Як показувати query controls? | Чотири окремі `react-native-actions-sheet`                                                              | Затверджений UI каталог і користувацький scope                                                                                                                                    | Inline Searchbar + Paper Menu/Modal                   | Потрібні повноцінні, прокручувані нижні панелі для кожного сценарію             |
| Коли запам'ятовувати пошук?   | Лише після explicit Apply; trim, case-insensitive deduplicate, 10 max                                   | User flow у `spec.md`                                                                                                                                                             | Зберігати кожне введення / не зберігати після restart | Історія має бути корисною, не містити випадкові чернетки та переживати restart  |
| Як застосовувати category?    | Category sheet має draft + Apply; filters sheet не містить category                                     | Окремий user request і чинний accordion selector                                                                                                                                  | Дублювати category selector усередині filters sheet   | Дублювання робить стан і UI неоднозначними                                      |
| Як прибрати query value?      | Один closeable Paper `Chip` на кожне значення                                                           | User request; current `CatalogActiveFilters` already owns active-query presentation                                                                                               | Один global Reset chip                                | Потрібне точкове видалення без втрати інших selections                          |
