# Research: catalog discovery UI

| Question                                 | Decision                                                                                                | Evidence / reference                                                                                                                                                              | Rejected alternative                                     | Reason                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Which SDD template?                      | `mobile-feature` plus an additional `visual-spec.md`                                                    | The task adds dependencies and persisted local state, not only styles                                                                                                             | `mobile-visual` only                                     | The visual template does not describe storage and dependency rollout in enough detail |
| Which theme should be used?              | Only the current `mobileLightTheme` / `mobileDarkTheme`                                                 | `libs/mobile/core/shell/src/theme/app-theme.ts`                                                                                                                                   | Themes from the two examples                             | The user explicitly prohibited changing the custom corporate theme                    |
| How should UX from the examples be used? | Reuse the structure: compact header, separate action controls, contrasting card surfaces, vertical list | `Ecommerce-mobile-template-main/src/screens/ShopScreen/*`, `.../ProductCard/*`; `react-native-expo-shop-template-main/src/components/ProductsListVertical.tsx`, `ProductCard.tsx` | Copying code, tokens, or navigation                      | The examples belong to other apps and have different state/theme boundaries           |
| How should a long list be rendered?      | Use `@shopify/flash-list` in `CatalogList`                                                              | Approved [catalog UI capabilities](../../../../architecture/mobile/platform/ui-capabilities.md)                                                                                   | Keep `FlatList`                                          | The architectural decision calls for FlashList for new or redesigned long lists       |
| How should query controls be presented?  | Four separate `react-native-actions-sheet` sheets                                                       | Approved UI catalog and user scope                                                                                                                                                | Inline Searchbar plus Paper Menu/Modal                   | Each scenario needs a full, scrollable bottom sheet                                   |
| When should a search be saved?           | Only after explicit Apply; trim, case-insensitive deduplication, maximum 10                             | User flow in `spec.md`                                                                                                                                                            | Save every keystroke / do not persist after restart      | History should be useful, exclude accidental drafts, and survive restarts             |
| How should category selection work?      | The category sheet has a draft and Apply; the filters sheet has no category selector                    | Separate user request and current accordion selector                                                                                                                              | Duplicate the category selector inside the filters sheet | Duplication makes state and UI ambiguous                                              |
| How should a query value be removed?     | One closeable Paper `Chip` per value                                                                    | User request; current `CatalogActiveFilters` already owns active-query presentation                                                                                               | One global Reset chip                                    | Values must be removable individually without losing other selections                 |
