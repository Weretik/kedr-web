# Requirements checklist: catalog discovery UI

- [x] Appbar, FlashList, cards, four sheets, chips та history описані acceptance scenarios.
- [x] Точні existing source paths і boundaries зафіксовані.

- [x] Локальні приклади обмежені UX reference; їхня тема не переноситься.
