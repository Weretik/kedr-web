# Фаза 12 — Ієрархія product card

## Мета

Зробити список товарів компактнішим і придатним для робочого каталогу: SKU/ID легко сканувати, назва не конкурує з ціною, а ціна та наявність читаються як один підсумковий рядок.

- [x] C061. Зберегти білу product card на сіруватому `background`, fixed white image frame та відступи поточного list layout.
- [x] C062. `ID` розмістити першим у текстовому блоці, зробити `bodySmall`/не збільшувати, але виділити `fontWeight: '700'`; це головний ідентифікатор для сканування.
- [x] C063. Назву зробити звичайної товщини (`fontWeight: '400'`) і трохи меншою за поточний `titleMedium`; максимум дві строки зберігається.
- [x] C064. Ціну лишити жирною. Розмістити ціну та availability в одному нижньому row: ціна зліва, статус справа. Availability зберігає семантичний зелений/червоний/жовтий колір і не виходить за межі card.
- [x] C065. Додати/оновити UI tests для hierarchy: ID, unbold title, bold price та горизонтальний price/status row.

## Acceptance

1. Card читається у порядку: жирний ID → стримана назва → один підсумковий рядок «ціна ліворуч / наявність праворуч».
2. Назва не має bold styling та не візуально конкурує з ID або ціною.
3. Ціна лишається bold, availability праворуч має правильний semantic color у light і dark theme.

## Checkpoint

Не переходити до спільного delivery-13, доки C061–C065 не виконані й не перевірені.
