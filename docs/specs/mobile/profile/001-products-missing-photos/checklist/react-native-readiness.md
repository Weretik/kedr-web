- [x] Expo Router file is designed as a thin adapter.
- [x] Mobile catalog library boundaries and public exports are identified.
- [x] Android, iOS, Expo web, safe area, orientation, scrolling, touch and
      accessibility risks are identified.

      are identified.

- [x] Expo Go is sufficient; no binary rebuild trigger is expected.
- [x] Actual Nx/Jest targets and existing tests were inspected.
- [x] Device verification is planned and E2E is intentionally not added.
- [x] Missing API contract, rather than test tooling, is represented by EN-001.
