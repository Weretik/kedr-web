# Architecture audit — Kedr Mobile structure after the «Пагін» redesign

- **Feature/SDD:** `docs/specs/mobile/redesign/001-pagin-design-system/`
- **Scope:** `apps/mobile/src`, all `libs/mobile/*` source files touched or grown by the redesign: responsibility per file, component and hook size, folder layout inside libraries
- **Date:** 2026-10-26
- **Applicable rules:** `docs/standards/mobile/mobile-code-organization.md` (one cohesive responsibility per file; split lists, cards, toolbars; screen / controller hook / reducer / controls / results split), `docs/standards/mobile/design-system.md` (theme values only, no hex in components), Nx `@nx/enforce-module-boundaries`
- **Size criteria:** the project defines no numeric limits; findings are based on mixed responsibilities, duplication, and inconsistent layout, not on line counts.
- **Status:** AF-001–AF-010 fixed and verified on 2026-10-26 in the same branch; AF-011 open, left to a separate configuration task.

## Not findings

- Screens in `*/feature/src/screens` stay thin adapters; route files in `apps/mobile/src/app` only pass params and navigation callbacks.
- `catalog-query-reducer.ts` (190 lines) is one pure reducer with private helpers; size alone is not a reason to split.
- `ui` libraries import no API hooks, router, or storage; `@mobile/shared/ui` depends only on `scope:mobile-shared`.

## Verification 2026-10-26

Public exports are unchanged; `index.ts` barrels re-export the moved files. Jest passes for every touched project (shared/ui, core/shell, catalog model/ui/feature, cart data-access/ui/feature, customers/ui, orders ui/feature, apps/mobile). ESLint on `libs/mobile` and `apps/mobile` shows only the existing `jsx-a11y/no-autofocus` error. `tsc` shows no new errors beyond AF-011. No device checks.
