# Як доручити AI створити Admin feature-специфікацію

Надішліть AI це повідомлення:

```text
Працюй за шаблоном `docs/specs/_templates/admin-feature/`.
Створи або онови специфікацію: `docs/specs/admin/<domain>/<NNN>-<feature-slug>`.
Опис feature: `<що має отримати користувач і основні вимоги>`.
Не реалізовуй код, доки я окремо не попрошу.
```

Приклад:

```text
Працюй за шаблоном `docs/specs/_templates/admin-feature/`.
Створи специфікацію: `docs/specs/admin/products/002-product-editor`.
Опис feature: адміністратор створює та редагує товар із валідацією полів,
збереженням через чинний API і повідомленням про помилку.
Не реалізовуй код, доки я окремо не попрошу.
```
