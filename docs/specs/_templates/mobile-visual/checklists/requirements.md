# Visual SDD requirements checklist

- [ ] Проблема має evidence, device/platform context і UX goal.
- [ ] Scope і non-goals не дозволяють непомітно розширити задачу.
- [ ] Є wireframe/reference, anatomy, interaction і state matrices.
- [ ] Documented loading, success, empty, error і relevant selected/expanded/disabled states.
- [ ] Documented Android scroll/safe area/touch та web keyboard/focus behavior.
- [ ] Кожна interactive зона має accessible name і один однозначний результат.
- [ ] Plan містить точні source paths і не додає API/data changes без feature SDD.
