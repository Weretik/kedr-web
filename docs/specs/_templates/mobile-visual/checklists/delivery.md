# Visual SDD delivery checklist

- [ ] Visual contract implementation and tests agree.
- [ ] Reused existing theme tokens and components; no local visual system introduced.
- [ ] Verified Android default, interaction, long-content and error states.
- [ ] Verified web pointer, keyboard, focus, dismiss and scroll behavior.
- [ ] Checked TalkBack/VoiceOver labels and touch target sizes.
- [ ] Stored automated/manual evidence and residual risks in `quickstart.md`.
