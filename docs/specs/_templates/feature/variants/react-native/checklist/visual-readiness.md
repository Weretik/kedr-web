# React Native visual readiness

- [ ] Observable visual/interaction behavior represented by `R-*` and `SC-*`.
- [ ] Approved references and their authority recorded.
- [ ] Anatomy, interaction and state matrices complete for in-scope states.
- [ ] Android, iOS and web differences explicit.
- [ ] Safe area, keyboard, focus, scrolling, touch and accessibility risks explicit.
- [ ] Existing components/tokens identified in design, not scenarios.
- [ ] Component, integration, manual and E2E levels selected by risk.
- [ ] Each visual responsibility has its own `TS-*` or `EN-*`.
