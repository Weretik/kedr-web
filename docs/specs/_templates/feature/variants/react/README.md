# React feature variant

Використовуй цей варіант для звичайного React Web застосунку. У поточному
репозиторії це Admin у `apps/admin` і `libs/admin`.

Під час створення feature додай файли цього каталогу до базової структури,
зберігаючи відносні шляхи:

- `design/react.md`;
- `checklist/react-readiness.md`.

Варіант визначає React Router/browser behavior, UI/accessibility, state і data
fetching, API boundary та фактичні Vitest/React Testing Library constraints.
Загальні `R-*`, `SC-*`, `TS-*`/`EN-*`, traceability і TDD залишаються у
базовому feature template.
