# Angular feature variant

Використовуй цей варіант для Angular Web застосунку. У поточному репозиторії
це Storefront SSR у `apps/storefront` і `libs/storefront`.

Під час створення feature додай файли цього каталогу до базової структури,
зберігаючи відносні шляхи:

- `design/angular.md`;
- `checklist/angular-readiness.md`.

Варіант визначає Angular routing, signals/services, SSR/hydration, locale,
template accessibility та фактичні test-tooling constraints. Він не запозичує
React component або hook assumptions.
