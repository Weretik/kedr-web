# Requirements checklist: <назва Mobile feature>

- [ ] CHK001 User stories мають пріоритет та independent test.
- [ ] CHK002 Functional requirements конкретні, перевірювані та не суперечать одна одній.
- [ ] CHK003 Edge cases охоплюють застосовні loading, empty, error, offline та route стани.
- [ ] CHK004 Success criteria вимірювані та не прив'язані до реалізації.
- [ ] CHK005 Усі Android/iOS/web припущення й зовнішні залежності зафіксовані.
