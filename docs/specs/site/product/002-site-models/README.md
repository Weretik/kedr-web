# 002 — Модели на сайте: категория, страница модели, поиск

- **Клиент:** публичный Next.js сайт, `apps/site`.
- **Домены:** `catalog` (списки), `product` (страница модели), `cart` (добавление нескольких вариантов).
- **Backend:** KedrStore spec catalog/007, этап 5 (публичный API моделей) и этап 6 (R-21: `productId` в карточке модели из одного товара).
- **Статус:** принято владельцем 2026-11-06 («Внедряй»); реализовано 2026-11-06 (этап 6), ждёт слияния.
- **Макет:** [«Кедр: моделі на сайті»](https://claude.ai/artifact/G1jtkkUC1y5ZRdM4iKhHDz), доски «Категорія» и «ПІДСУМОК: сторінка моделі». Основа — [«Кедр: моделі та ознаки»](https://claude.ai/artifact/DYfVE9Kkxc6RGD293mjXNV).

Модель — одна страница сайта в одной конечной категории, которая объединяет товары 1С (цвет, размер, сторона). Товар вне погодженої модели показывается как модель из одного товара под своим адресом (007 M-04, решение владельца 2026-11-06: непогоджені модели на сайт не выводятся).

## Решения

- **D-01. Адрес.** Страница модели живёт на прежнем маршруте `/{locale}/product/{slug}`: `slug` — адрес модели или товара-модели. Выбор варианта — query `?{ось}={значение}` (слаги ознак). Канонический адрес — без query. Так большинство ссылок не меняется; товар внутри погодженої модели отвечает 308 на адрес модели с его значениями (007 R-17).
- **D-02. Переключатели — ссылки.** Выбор варианта перерисовывает страницу на сервере (`Link` без прокрутки): цена, наличие, фото и артикул выбранного товара есть в исходном HTML, клиентский JS для выбора не нужен.
- **D-03. Карточка в списке = модель.** Списки категории и поиска берут `GET api/catalog/{lang}/{category}/models` и `GET api/catalog/{lang}/models`. Модель из нескольких товаров показывает «від» цену, кружки цветов и число вариантов; модель из одного товара — артикул и «У кошик» как раньше.
- **D-04. Фильтры по ознакам** только в конечной категории (007 M-09), из `filters` ответа, в query `?{ознака}={значение},{значение}`; страницы с фильтрами `noindex`, как остальные фильтры.
- **D-05. Таблица всех вариантов** с количеством на каждый и «Додати вибране в кошик» — владелец корзины (`cart`), строки собирает `product`.
- **D-06. Поиск:** точный код 1С (`exactMatch`) сразу ведёт на модель с выбранным вариантом.

## Правила

- **R-01.** Страница модели: фото и описание выбранного товара (текущий загрузчик товара), H1 — название модели, под ним название выбранного товара; короткий опис модели; переключатели по осям; первая ось показывает все свои значения, каждая следующая — только значения, которые есть в паре с выбором осей перед ней (так любой товар достижим, а несуществующие сочетания не показываются); клик ведёт на товар с этим значением, ближайший к текущему выбору; «Скинути вибір» не нужен — выбор всегда полный (по умолчанию основной товар, иначе первый в наличии).
- **R-02.** Выбранный товар не в наличии: «Немає в наявності» и до трёх кнопок «Є в наявності: …» — варианты в наличии, первыми те, у которых больше общих значений осей (у модели с одной осью общих значений нет, поэтому показываются любые варианты в наличии).
- **R-03.** Полный опис модели и SEO-заголовок/опис из «Вітрини сайту»; пустой опис — описание товара не дублируется. Характеристики модели — таблица.
- **R-04.** Внизу «Інші моделі в категорії» — до 4 моделей той же категории в наличии, кроме текущей.
- **R-05.** Модель из одного товара (`isAccepted=false`) — прежняя страница товара без изменений.
- **R-06.** Карта сайта товаров перечисляет адреса моделей (без адресов, которые отвечают 308).
- **R-07.** Страница читает `searchParams`, поэтому рендерится на каждый запрос; данные модели, товара и списков берутся из `'use cache'`, отдельного запроса к API на рендер нет.

## Сценарии

- **SC-01 (D-03).** Конечная категория показывает погоджену модель «від» ценой, кружками и числом вариантов, а товар-модель — с артикулом и «У кошик».
- **SC-02 (D-04).** Фильтр по ознаке оставляет подходящие модели, показывает счётчики, сбрасывается; в родительской категории фильтров ознак нет.
- **SC-03 (D-01, R-01).** `/product/{model}` без query выбирает основной товар; `?{ось}={значение}` выбирает свой; несуществующее значение даёт выбор по умолчанию.
- **SC-04 (D-01).** Адрес товара внутри погодженої модели отвечает 308 на `/product/{model}?{ось}={значение}`.
- **SC-05 (R-02).** Выбранный вариант не в наличии — блок «Є в наявності» со ссылками.
- **SC-06 (D-05).** В таблице указывают количество двух вариантов и добавляют их в корзину одним нажатием.
- **SC-07 (D-06).** Поиск по точному коду 1С ведёт на модель; по слову из названия товара — находит его модель.
