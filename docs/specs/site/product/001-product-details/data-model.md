# Модель данных

## ProductDetails — реализованная модель `product/model`

| Поле                             | Источник / правило                                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `sku: string`                    | `ProductDetails.id`, код 1С, показ и копирование без перевода                                                                         |
| `slug: string`                   | текущий `productSlug`; непустой безопасный сегмент, без самостоятельной транслитерации                                                |
| `name: string`                   | непустое локализованное имя; незаполненная обязательная идентичность — некорректный ответ, не демонстрационная карточка               |
| `price: number \| null`          | конечное число >0; всё остальное → `null`; retail UAH, тип 11                                                                         |
| `inStock: boolean`               | конечный `stock > 0`; числовой остаток не входит в публичную модель                                                                   |
| `quantityInPack: number \| null` | положительное целое, иначе `null`; только информация                                                                                  |
| `categoryName`, `categorySlug`   | валидные исходные значения; неполная категория не создаёт битую ссылку                                                                |
| `breadcrumbs`                    | нормализованные исходные категории с id, без дублей; feature строит видимый trail и исключает «Фурнітура»/Cosmos общей catalog policy |
| `media: ProductMediaItem[]`      | независимо нормализованные photo/scheme, сначала фото; уникальные URL                                                                 |
| `updatedAt: string \| null`      | валидная исходная дата; не подставлять дату сборки/запроса                                                                            |

`ProductMediaItem = { kind: 'photo' | 'scheme'; url: string }`. Допускаются только HTTPS URL разрешённого хоста `images-kedr.cdn.express`, без credentials и опасных схем. Не расширять host allowlist ради отдельного некорректного значения.

## Результат чтения

`ProductResult` — `found(product)` / `moved(currentSlug)` / `category-redirect(categorySlug)` / `not-found` / `unavailable(reason)`. Конкретное представление union выбирается в TS-001; семантика фиксирована. `gone` транспорта не означает подтверждённую удалённую сущность с 410: такой ответ текущей операции не описан.

## Независимые состояния

| `inStock` | `price` | Главное действие                                     | Количество |
| --------- | ------- | ---------------------------------------------------- | ---------- |
| true      | >0      | «У кошик» после EN-002                               | разрешено  |
| true      | null    | «Запитати ціну» → контакты                           | недоступно |
| false     | >0      | «Уточнити наявність» → контакты                      | недоступно |
| false     | null    | «Уточнити наявність», цена по запросу остаётся видна | недоступно |

Медиа независимо от этой таблицы: оба / только фото / только схема / ни одного. Отказ загрузки — локальное состояние выбранного URL. При отказе активного URL выбрать оставшийся исправный; если их не осталось — единый fallback, счётчик и ложные миниатюры скрыты. Уменьшение числа изображений не меняет состояние покупки.

## Количество и корзина

Локально хранится только выбранное положительное целое количество и состояние текущей операции. Начальное значение 1. Не переносить из концепта `max=99`, `cart`, цену 420 и упаковку 10. Допустимый верхний предел и дополнительные проверки приходят от cart owner после EN-002. Клиентская проверка не доказывает резервирование или актуальный склад.

Содержимое и счётчик корзины принадлежат общему cart domain. Product не заводит вторую persisted корзину. Идентичность строки и политика повторного добавления определяются его согласованным контрактом.

## SEO input

`product/feature` передаёт в `product/seo` простые поля идентичности, цены, наличия, медиа, видимых хлебных крошек и подтверждённых языковых URL. Тип input объявлен в `product/seo`, чтобы `type:util` не импортировал `product/model`. SKU/name/price/availability для HTML и SEO берутся из одной нормализованной версии товара.
