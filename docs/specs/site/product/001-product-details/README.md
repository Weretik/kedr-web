# 001 — Детальная страница товара Kedr

- **Клиент:** публичный Next.js сайт, `apps/site`.
- **Домен:** `product`; отдельные `model`, `data-access`, `ui`, `seo`, `feature` согласно [карте модулей](../../../../architecture/site/structure/modules.md).
- **Статус:** независимый этап 4A реализован и проверен автоматическими/source checks 2026-11-03; полный purchase flow blocked EN-002/TS-005.
- **Реализация:** EN-001, TS-001/002/003/004/006/007/008 выполнены для 4A; TS-009 закрывает evidence 4A, полная поставка ожидает общую корзину.
- **Владелец:** frontend Kedr; общий cart foundation — владелец шага 5 миграции.
- **Создано / обновлено:** 2026-11-03.

Покупатель открывает товар из каталога или по прямой ссылке, видит реальное фото/схему, название, артикул, розничную цену и наличие, выбирает количество и добавляет доступный товар в общую корзину. При отсутствии цены или наличия предусмотрен контакт с менеджером. Страница следует принятой композиции, поддерживает UK/RU, светлую/тёмную темы и мобильные экраны; основной контент доступен в исходном HTML.

## Принятый дизайн и границы

Пользователь принял направление концепта и запросил SDD для его переноса в проект. [Сохранённый HTML-концепт](design/concept.html) — визуальный ориентир; [нормативный дизайн](design/visual.md) уточняет его для реальных данных и интеграций. Демонстрационные данные, локальная корзина, предел количества 99 и переключатели показа состояний в продукт не переносятся.

Маршрут: `/{locale}/product/{slug}`. Существующие ссылки каталога и legacy redirect сохраняются. Используется текущий публичный контракт; изменений backend в этой SDD нет. Checkout, кабинет, авторизация и разработка общей корзины целиком остаются отдельным шагом миграции. Сценарии покупки здесь описаны до границы готового cart owner, а не исключены из целевого результата.

## Готовность и ограничения

1. **EN-001, выполнена:** пять libraries созданы Nx-генератором, aliases/targets и узкий product-feature→catalog-model flow подтверждены. Независимые данные/UI/SEO/route/sitemap реализованы.
2. **EN-002, blocked:** общий Site cart ещё не реализован. До подтверждения его public API, сохранения состояния, счётчика и рабочего адреса корзины TS-005 и полная поставка заблокированы. Другие задачи не ждут корзину.
3. Доступный товар с ценой сохраняет целевое действие «У кошик». До EN-002 не публиковать имитацию успешной покупки и не заменять её несогласованным действием. Выпуск страницы до общей корзины потребует отдельного решения владельца о временном поведении.
4. Контракт не содержит произвольных характеристик, описания, бренда, вариантов и отзывов. Эти блоки не включены; это не блокер карточки.

Порядок миграции без цикла: **4A — читаемая карточка/UI/SEO → 5 — cart foundation → 4B — подключение покупки TS-005**. Шаг 5 ожидает 4A, а не полную готовность 4B. EN-001 фиксирует эту последовательность в плане перед запуском зависимых работ; номер шага не делает EN-002 следствием завершённой полной покупки.
