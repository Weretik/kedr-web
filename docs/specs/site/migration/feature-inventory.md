# Опись фич текущей витрины и SEO-анализ

**Проверено:** 2026-10-29 по коду `apps/storefront` и `libs/storefront/*` (Angular 21, Cloudflare Pages). Карточки текущих фич: [каталог фич](../../../features/README.md#storefront-angular). Общие SEO-решения нового сайта: [SEO-архитектура](../../../architecture/site/platform/seo-architecture.md).

## Общие проблемы всей витрины

Эти проблемы касаются каждой страницы; оболочка нового сайта уже решает пункты 1–6.

| #   | Сейчас                                                                                                    | Почему плохо для SEO                                       | В новом сайте                                                            |
| --- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1   | `<title>Class Kedr</title>` на всех страницах, нет `description`                                          | поисковик не понимает, о чём страница; одинаковые сниппеты | уникальные title и description из `buildPageMetadata` (оболочка готова)  |
| 2   | `<html lang="en">` для украинских и русских страниц                                                       | неверный язык страницы                                     | `lang="uk-UA"` / `ru-UA` (готово)                                        |
| 3   | Нет `robots.txt` и `sitemap.xml`                                                                          | поисковик ищет страницы сам, медленно                      | `robots.ts`, `sitemap.ts`, позже индекс sitemap по типам (готово базово) |
| 4   | Неизвестный адрес редиректит на `/uk/404`, а Pages может отдать `404.html` со статусом 200 и meta refresh | «мягкие» 404 засоряют индекс                               | настоящий статус 404 и `noindex` (готово)                                |
| 5   | Нет JSON-LD                                                                                               | нет расширенных сниппетов (цена, наличие, крошки)          | Organization и WebSite готовы, остальное по фичам                        |
| 6   | Иконки Telegram и Viber с `cdn.simpleicons.org`, PrimeNG и PrimeIcons                                     | лишние запросы и вес, хуже Core Web Vitals                 | lucide-иконки и `next/font` (готово)                                     |
| 7   | canonical и hreflang ставит браузерный сервис `SeoHreflangService` (`ru-UA`, `uk-UA`, `x-default`)        | работает, но главная получает адрес `/uk/` со слэшем       | без слэша: `/uk`, единый билдер (готово); `/uk/` → 308 на `/uk`          |
| 8   | Главная `/` редиректит на `/uk` в браузере                                                                | сервер отдаёт пустую оболочку                              | 308 на сервере (готово)                                                  |

## Главная и категории

**Сейчас.** Локализованный корень `/uk` открывает страницу [categories](../../../features/storefront/catalog/categories.md): разделы фурнитуры и дверей из констант `CATALOG_*` в `@storefront/data-access`. Готовая библиотека `home` не подключена. Тот же экран доступен по `/categories` — это дубль.

**SEO сейчас.** Один заголовок сайта, нет H1 с ключевой фразой, нет описания. Дубль `/` и `/categories`.

**Что изменить.**

- Главная по макету: H1 «Дверна фурнітура оптом і в роздріб», поиск по артикулу, блок «Оптовим партнерам», указатель каталога (шесть разделов с подкатегориями ссылками — сильная перелинковка), популярные позиции, три факта, подвал.
- Title «Дверна фурнітура оптом і в роздріб — Class Kedr», description с основными разделами и «доставка по Україні».
- `/categories` → 301 на `/{locale}` (или на будущий `/catalog/products`), чтобы не было дубля.
- JSON-LD: `WebSite` (готово), позже `SearchAction`.
- Разделы брать из API `GET /api/catalog/{lang}/categories` вместо констант, чтобы меню не расходилось с 1С.

**Новый сайт.** Маршрут `app/[locale]/page.tsx` → `libs/site/home/feature`. Статика с ревалидацией по тегу `catalog`.

## Список товаров категории

**Сейчас.** [ProductListPage](../../../features/storefront/catalog/catalog.md): крошки, подкатегории, фильтры (`inStock`, `isSale`, `isNew`, `priceFrom`, `priceTo`), сортировка, пагинация `page`/`pageSize`, поиск `search`. Страницы категорий пререндерятся при сборке для всех слагов из констант; список товаров запрашивается из API.

**SEO сейчас.**

- Нет уникального title и description у категории, нет текста о категории.
- По умолчанию стоит фильтр «Тільки в наявності» (`inStock=true`); товары без остатка не видны поисковику.
- Любая комбинация фильтров и сортировки создаёт новый адрес без canonical на категорию — дубли.
- Нет `BreadcrumbList` и `ItemList`, пагинация не ссылками.

**Что изменить.**

- Адрес сохранить: `/{locale}/catalog/{slug}/products`.
- Первый HTML содержит H1, крошки, первую страницу товаров и ссылки пагинации (`?page=2`).
- Title «{Категорія} — купити оптом і в роздріб | Class Kedr», description из названия и числа товаров; позже SEO-текст категории из API.
- Правило фильтров ([SEO-архитектура](../../../architecture/site/platform/seo-architecture.md#url-and-index-policy)): страница 1 и пагинация индексируются; комбинации фильтров, сортировка, `pageSize` и вид «таблица» — `noindex, follow` с canonical на категорию. Белый список одно-значных фильтров-посадочных утверждаем отдельно.
- JSON-LD: `BreadcrumbList` из `CategoryDetails.breadcrumbs`, `ItemList` товаров страницы.
- Неизвестный слаг — 404 (сейчас пустая страница).
- Пустой результат фильтра — 200 с `noindex` и кнопкой «Скинути фільтри».
- Вид «плитка / таблица» для опта хранить в cookie или localStorage, не в URL.

**Новый сайт.** `app/[locale]/catalog/[categorySlug]/products/page.tsx` → `libs/site/catalog/feature`. ISR: `generateStaticParams` для разделов верхнего уровня, остальные по запросу; тег `category:{slug}`. Фильтры — клиентский остров, состояние в URL.

## Все товары и поиск

**Сейчас.** `/{locale}/catalog/products` — общий список и результаты поиска из шапки (`?search=`).

**SEO сейчас.** Результаты поиска могут попасть в индекс как бесконечное число адресов.

**Что изменить.** Страница без параметров — индексируемый общий каталог (или 301 на главную, решить). С `search` — `noindex, follow`, canonical на `/{locale}/catalog/products`. Подсказки поиска и горячая клавиша `/` — клиентский остров в шапке.

**Новый сайт.** `app/[locale]/catalog/products/page.tsx`, динамический рендер по нормализованному запросу.

## Страница товара

**Сейчас.** [ProductPage](../../../features/storefront/catalog/catalog.md) читает товар по слагу (`GET /api/catalog/{lang}/product/{productSlug}`): название, фото, схема, остаток, цена, упаковка, крошки. Рендеринг только в браузере: Cloudflare Worker отдаёт `index.csr.html`.

**SEO сейчас — главная проблема сайта.** Поисковик получает пустой шаблон без названия, цены и фото. Нет title, description, Product JSON-LD, Open Graph картинки; несуществующий товар не даёт 404.

**Что изменить.**

- Полный серверный HTML: H1 с названием, артикул, цена, наличие, фото через `next/image` (главное фото `priority`), крошки.
- Title «{Назва} {артикул} — ціна, купити | Class Kedr», description из категории, цены и наличия.
- JSON-LD: `Product` + `Offer` (`price`, `priceCurrency: "UAH"`, `availability` InStock/OutOfStock), `BreadcrumbList`.
- Open Graph: фото товара.
- Неизвестный слаг — 404; снятый с продажи — 410, когда API начнёт это отдавать.
- Блок «Оптова ціна доступна партнерам» со ссылкой на вход — без цены в HTML, чтобы не отдавать персональные цены в кеш.
- Блоки «Характеристики / Опис / Доставка та оплата», «З цим купують» (внутренние ссылки).

**Нужно от бэкенда.** В `ProductDetails` нет артикула, описания, характеристик, бренда, нескольких фото и `updatedAt`. Без этого страница будет беднее макета; требования записаны в [SEO-архитектуре](../../../architecture/site/platform/seo-architecture.md#backend-requirements).

**Новый сайт.** `app/[locale]/catalog/product/[productSlug]/page.tsx` → `libs/site/product/feature`. ISR по слагу, тег `product:{id}`. После переключения Worker-правило `_worker.js` больше не нужно.

## Корзина и оформление

**Сейчас.** [Корзина](../../../features/storefront/catalog/cart.md) — панель в шапке на сигналах (`CartStore`). [Оформление](../../../features/storefront/catalog/checkout.md) `/checkout` — форма контактов, `POST /api/orders` (быстрый заказ уходит Excel-файлом в Telegram и не сохраняется в базе).

**SEO.** Приватные страницы: не индексировать, но сейчас нет ни `noindex`, ни запрета в robots.

**Что изменить.**

- `noindex` и `Disallow` для `/checkout` (в оболочке уже в robots-политике), ссылки на корзину с `rel="nofollow"` (готово в шапке).
- Корзина — клиентский остров (Zustand или React context; решить в SDD), хранение в localStorage, счётчик и сумма в шапке.
- Два режима из макета: «Швидке замовлення» (имя и телефон) и «Повне оформлення» (Нова пошта).
- Корзина не влияет на кеш индексируемых страниц.
- Отдельно от SEO: сохранять заказы с сайта в базе KedrStore (идея из [feature-ideas](../../../ideas/feature-ideas.md)).

**Новый сайт.** `libs/site/cart/{model,ui,feature}`, маршрут `app/[locale]/(private)/checkout`.

## Статьи

**Сейчас.** [Статьи](../../../features/storefront/content/articles.md): шесть статей, текст и картинки в коде (`article-list.data.ts`), адреса по номеру `/articles/1`…`/articles/6`.

**SEO сейчас.** Адрес без смысла (`/articles/3`), нет title, description, даты, `Article` JSON-LD.

**Что изменить.**

- Адреса-слаги по названию (`/articles/yak-obraty-dvernyi-zamok`) и 301 со старых `/articles/{id}`.
- Title, description, дата публикации и обновления, `Article` JSON-LD, Open Graph картинка.
- Ссылки из статей на категории и товары.
- Контент: проверить, что статьи только о фурнитуре и её выборе, без услуг монтажа.
- Позже — хранение статей вне кода (MDX в репозитории или CMS; решить в SDD).

**Новый сайт.** `libs/site/content`, статика.

## Страницы компании и юридические

**Сейчас.** [Семь страниц](../../../features/storefront/content/about-us.md): `about-company`, `delivery-and-payment`, `galleria`, `returns-exchanges`, `requisites`, `privacy-policy`, `public-offer`. Текст в переводах Transloco.

**SEO сейчас.** Нет title и description. Галерея — картинки без подписей и `alt`-текстов по смыслу (проверить при переносе).

**Что изменить.**

- Адреса сохранить.
- Уникальные title и description; на «Доставка та оплата» и «Повернення» — короткие FAQ-блоки (полезно и людям, и поиску).
- Юридические страницы (оферта, политика, реквизиты) оставить индексируемыми, но без попадания в sitemap как приоритетных — решить.
- Галерея: подписи, `alt`, `next/image`, ленивые картинки.
- Перечитать «Про компанію» на соответствие рамкам бизнеса: только продажа фурнитуры.

**Новый сайт.** `libs/site/content`, статика, тексты переносятся из переводов в словари `uk`/`ru` фичи.

## Контакты

**Сейчас.** [Контакты](../../../features/storefront/content/contacts.md): заголовок и форма, которая никуда не отправляет.

**SEO сейчас.** Нет адреса, часов работы и карты в разметке; нет `LocalBusiness`.

**Что изменить.**

- Телефон, email, адрес, часы, карта, мессенджеры — текстом в HTML.
- JSON-LD `Store`/`LocalBusiness` с адресом и часами (данные даёт владелец).
- Форму либо подключить (Server Action → Telegram или KedrStore), либо убрать — нерабочая форма вредит доверию.

## Регионы

**Сейчас.** [Регионы](../../../features/storefront/content/regions.md): 23 адреса `/region/{city}`, один шаблон текста с подстановкой названия региона.

**SEO сейчас — риск.** 23 почти одинаковые страницы похожи на «дорвеи»: поисковик может понизить сайт. В тексте есть «Експертний підбір та реновація» и кнопка «Демонстрація» — это противоречит рамкам бизнеса (без услуг) и выглядит как остаток шаблона.

**Что изменить.**

- Индексировать страницу региона только при уникальном тексте: сроки и стоимость доставки в регион, перевозчики, популярные товары, отзывы клиентов из региона. Без такого текста — `noindex, follow` или объединить в одну страницу «Доставка по Україні».
- Убрать формулировки про реновацию и подбор.
- Ссылки на регионы из меню «Регіони» оставить (меню уже есть в шапке оболочки).

**Решение владельца:** `[NEEDS CLARIFICATION: оставлять 23 региональные страницы с уникальным текстом или объединить]`.

## Неподключённые библиотеки

[Главная `home`](../../../features/storefront/home.md) и [блок «В наличии»](../../../features/storefront/widgets.md) есть в коде, но не подключены. Идеи из них (популярные позиции, «В наличии») переносятся в главную на шаге 2, код не переносится.
