# Правила и сценарии

Технические решения находятся в [frontend-дизайне](../design/frontend.md), визуальная структура и согласованные тексты — в [дизайне страницы](../design/visual.md). Ниже только наблюдаемый результат.

## Правила

| ID    | Правило                                                                                                                                                                                       |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-001 | Страница публична и доступна по сохранённым адресам `/uk/contacts` и `/ru/contacts` без авторизации.                                                                                          |
| R-002 | Посетитель видит хлебные крошки, заголовок, краткое вступление, разделы связи, местоположения, сотрудничества и подготовки к обращению в утверждённом порядке.                                |
| R-003 | Телефон, email, город и внешние ссылки соответствуют единому текущему источнику компании; улица, часы работы, срок ответа и коммерческие обещания не выдумываются.                            |
| R-004 | Главный контактный путь — звонок. Номер и кнопка звонка открывают один и тот же номер; копирование — отдельное действие с обратной связью рядом с ним. Сбой копирования не инициирует звонок. |
| R-005 | Telegram, Viber и email доступны прямыми подписанными ссылками. Сайт не изображает отправку сообщения или заявки.                                                                             |
| R-006 | Блок местоположения показывает подтверждённый город, открывает текущую ссылку на карту и предлагает уточнить адрес и время перед визитом.                                                     |
| R-007 | Блок сотрудничества ведёт к менеджеру через Telegram. Полезные ссылки ведут на доставку/оплату и возврат/обмен в текущем языке.                                                               |
| R-008 | Весь текст, доступные имена, обратная связь, metadata и хлебные крошки соответствуют выбранной локали; смена языка сохраняет страницу контактов.                                              |
| R-009 | Светлая/тёмная темы, телефон, планшет и desktop сохраняют читаемость, порядок содержимого и доступность действий. Цвета и оболочка следуют дизайн-системе сайта.                              |
| R-010 | Контакты доступны с клавиатуры, фокус виден, иконки действий имеют имена, сообщения копирования доступны зряче и средствам чтения. Переход к основному содержимому остаётся доступен.         |
| R-011 | Основной текст, контакты, ссылки и SEO доступны в исходном серверном HTML; для чтения контактов и перехода по ссылкам JavaScript не требуется.                                                |
| R-012 | Каждая локаль имеет свой title, description, canonical, взаимные языковые alternates и Open Graph. Локальная/preview-индексация остаётся выключенной действующим правилом.                    |
| R-013 | Структурированные данные соответствуют видимому содержимому: одна организация на странице и хлебные крошки «главная → контакты», без неподтверждённых адреса, часов или координат.            |
| R-014 | После реализации оба канонических URL включены в sitemap ровно по одному разу, с действующими языковыми alternates; фиктивная дата изменения не публикуется. Существующие URL сохраняются.    |

## Данные и незадействованные состояния

Телефон, email и ссылки — публичные сведения, пользовательские данные не собираются. Статическая страница не имеет ожидания API, пустого ответа или сетевой ошибки загрузки собственных данных. У копирования есть состояния idle, pending, success и unavailable/rejected. Для внешних приложений сайт предоставляет ссылку; успешный запуск приложения или отправка сообщения им не обещаются.

Проверка реальной отправки, звонка, буфера ОС или внешней карты не является автоматическим действием при приёмке. Полные suites, build, браузер и E2E требуют отдельного поручения по [правилам проверок](../../../../../standards/shared/testing-rules.md).
