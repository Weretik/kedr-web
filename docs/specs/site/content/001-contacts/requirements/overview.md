# Контакты — границы и источники

## Результат

Одна публичная страница в двух локалях: `/uk/contacts` и `/ru/contacts`. Страница помогает связаться с отделом продаж дверной фурнитуры оптом и в розницу и подготовить список товаров для обращения.

Включено: хлебные крошки, один H1, вводный текст, телефон с действием звонка и копированием, мессенджеры, почта, город и ссылка Google Maps, памятка для оптового заказа, адаптивность, темы, локализация, metadata, JSON-LD и sitemap.

Исключено: форма, приём или хранение сообщений, Server Actions, новые API, аналитика обращений, кабинет, корзина, остальные контентные страницы, полная карта с iframe, адрес улицы, часы работы, обещания времени ответа и условий опта, команда и её фотографии. Изображение концепта не вставляется в страницу вместо живого текста.
