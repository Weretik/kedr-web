# Контакты — SEO-дизайн

Применяются [SEO rules](../../../../../standards/site/seo-rules.md) и [SEO-архитектура](../../../../../architecture/site/platform/seo-architecture.md). Правила R-010…R-012 и сценарии SC-012…SC-014 — в [требованиях](../requirements/behavior.md).

## Metadata

| Поле                           | uk                                                                                                                             | ru                                                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Title до общего шаблона бренда | Контакти — зв’язок із відділом продажу                                                                                         | Контакты — связь с отделом продаж                                                                                                |
| Description                    | Контакти Class Kedr, Харків: телефон (068) 713-50-49, Telegram, Viber та електронна пошта. Дверна фурнітура оптом і в роздріб. | Контакты Class Kedr, Харьков: телефон (068) 713-50-49, Telegram, Viber и электронная почта. Дверная фурнитура оптом и в розницу. |
| Canonical                      | `/uk/contacts`                                                                                                                 | `/ru/contacts`                                                                                                                   |
| Open Graph locale              | `uk_UA`                                                                                                                        | `ru_UA`                                                                                                                          |

`content/seo` владеет title/description и вызывает общий `buildPageMetadata`. Общий layout добавляет шаблон `%s | Class Kedr`; бренд не дублируется. Номер и город в description подставляются из `COMPANY`, пример выше фиксирует текущий результат. Ограничение при проверке: итоговый title до 60 символов и description до 160 при текущих данных, без обрезания текста в рантайме.

На обеих страницах alternates: `uk-UA` → `/uk/contacts`, `ru-UA` → `/ru/contacts`, `x-default` → `/uk/contacts`. `metadataBase` делает адреса абсолютными. Query-параметры не входят в canonical, alternates, OG url и sitemap.

Robots строится общей политикой: только `SITE_ENV=production` вместе с `SITE_INDEXING=true` позволяет индексацию; в остальных окружениях `noindex, nofollow`. Флаги, robots.txt и политику всего сайта эта функция не меняет. Отдельного запрета `/contacts` в robots.txt не требуется.

## Структурированные данные

`buildContactsJsonLd(locale)` формирует данные для существующего `JsonLd`, который безопасно экранирует JSON:

- `ContactPage`: абсолютные `@id` (`{canonical}#webpage`) и `url`, локализованное имя, `inLanguage` (`uk-UA` / `ru-UA`), `mainEntity` → `${siteUrl}/#organization`.
- `BreadcrumbList`: главная текущей локали и контакты с последовательными позициями 1/2 и абсолютными URL; названия совпадают с видимыми крошками.
- `Organization`, её phone/email/город и `ContactPoint` уже выводятся layout; повторно их не создавать.

`LocalBusiness` / `Store` из общего плана миграции не входит в эту версию: точные адрес и часы не подтверждены. Утверждённый концепт показывает только город. В TS-003 общая таблица схем уточняется до фактической `ContactPage` с явно будущей LocalBusiness, без выдуманного адреса, часов, geo, отзывов и рейтинга.

## Sitemap

`getContactsSitemapPages()` возвращает одну locale-free запись `/contacts`; общий `buildSitemapEntries` создаёт uk/ru и взаимные языковые ссылки. `lastModified` отсутствует: достоверной даты обновления контента нет. Остальные записи home/catalog сохраняются. Отключение индексации остаётся в robots/metadata по текущему контракту общих builders.

## Доказательства

План и статус в [SEO verification](../verification/seo-verification.md). При разработке unit-тесты проверяют метаданные, обе конфигурации robots, схемы и sitemap; server-render тест подтверждает HTML без клиентской загрузки. Production build и запросы к запущенному сайту требуют отдельного расширения разрешённого объёма; результаты до их запуска не считаются полученными.
