# Правила и наблюдаемые сценарии

Технические владельцы — в [frontend](../design/frontend.md), copy и источники — в [content](../design/content.md). IDs сохраняются после принятия.

## Правила

| ID    | Название                     | Правило                                                                                                                                                                                                                                                        |
| ----- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-001 | Публичность и адреса         | Страница доступна без авторизации по /uk/wholesale и /ru/wholesale. Неподдерживаемая локаль не показывает украинский вариант вместо ошибки.                                                                                                                    |
| R-002 | Предложение и порядок блоков | Посетитель видит товарный H1, вводный текст и действия, ассортимент, сведения о Class Kedr, шаги заказа, FAQ и финальный контакт в принятой последовательности.                                                                                                |
| R-003 | Достоверные факты и условия  | Используются только подтверждённые сведения Class Kedr. Оптовые цены, наличие и условия посетитель уточняет у менеджера; публичные пороги, скидки, гарантии, статистика или услуги не придумываются.                                                           |
| R-004 | Действительный ассортимент   | Показываются доступные группы дверной фурнитуры из актуального каталога в его порядке. Двери и скрытые внутренние группы не включаются в эту витрину. Нельзя создавать отсутствующие группы, адреса, цены или счётчики.                                        |
| R-005 | Переход к товарам            | Фото/название категории открывает соответствующий раздел выбранного языка. Компактные карточки не показывают цены, количество товаров или список подкатегорий. Действие каталога ведёт в общий каталог.                                                        |
| R-006 | Связь с менеджером           | Основной и финальный CTA ведут в Telegram Class Kedr; номер открывает звонок, Viber предоставляет соответствующую ссылку. Переход происходит по действию посетителя, без автоматической отправки и без формы сбора данных.                                     |
| R-007 | Полезные переходы            | Хлебные крошки, компания, доставка и возвраты ведут в действительные локализованные разделы. Компания открывается в разделе компании главной.                                                                                                                  |
| R-008 | Недоступность каталога       | При временно недоступных или пустых группах основное предложение, сведения компании, FAQ и контакты сохраняются, а область ассортимента сообщает о недоступности и предлагает каталог/менеджера. Частичный ассортимент не дополняется вымышленными карточками. |
| R-009 | Полнота двух языков          | Украинская и русская версии имеют равнозначное содержание, действия и сообщения. Смена языка сохраняет страницу сотрудничества.                                                                                                                                |
| R-010 | Темы и адаптивность          | В обеих темах и на поддерживаемых ширинах сохраняются читаемость, порядок и действия. На телефоне категории идут в две колонки, шаги и FAQ читаются последовательно.                                                                                           |
| R-011 | Доступная семантика          | Страница имеет один основной заголовок, понятные имена ссылок, естественный порядок клавиатурного перехода и видимый фокус. Общий контейнер основного содержимого не дублируется; текст не заменён изображением макета.                                        |
| R-012 | Поисковое содержание         | Основное содержимое и действительные переходы доступны в исходной серверной странице. У каждой локали собственные принятые заголовок/описание и социальное представление, соответствующие видимому предложению.                                                |
| R-013 | Языковые поисковые адреса    | Каждая версия указывает свой канонический адрес, обе действительные языковые версии и украинскую версию как общую языковую точку входа. Межъязыковой canonical не используется.                                                                                |
| R-014 | Политика индексации          | Индексация разрешается только существующей production-политикой сайта. Новая страница не открывает тестовые/preview среды для индексации.                                                                                                                      |
| R-015 | Разметка сведений            | Хлебные крошки отражают видимый путь на том же языке. Сведения организации не дублируются; страница не выдаётся за отдельный товар и не содержит вымышленных рейтингов, цен или адресов.                                                                       |
| R-016 | Sitemap                      | В карте сайта каждая языковая версия wholesale представлена один раз с согласованными языковыми связями. Отсутствующая достоверная дата изменения не придумывается, соседние страницы сохраняются.                                                             |

## Given / When / Then

### SC-001 — Публичная страница

**Covers:** R-001, R-002, R-009. **Test level:** Component + focused integration.

**Given:** Посетитель выбирает украинскую или русскую версию.

**When:** Он открывает страницу сотрудничества без входа.

**Then:** Он видит принятое предложение и все смысловые блоки на выбранном языке.

### SC-002 — Узнать условия

**Covers:** R-003, R-006. **Test level:** Component ссылок, без реального звонка/отправки.

**Given:** Посетителю нужны цены и детали оптовой закупки.

**When:** Он выбирает основной CTA, финальный CTA, телефон или Viber.

**Then:** Предоставляется соответствующий способ связи Class Kedr; сообщение не отправляется автоматически и публичные условия не подставляются.

### SC-003 — Полный ассортимент

**Covers:** R-004, R-005. **Test level:** Catalog component + feature integration.

**Given:** Доступны текущие шесть групп фурнитуры и группы дверей/внутренние разделы.

**When:** Посетитель читает ассортимент и выбирает группу.

**Then:** Показаны действительные группы фурнитуры в порядке каталога с фото/нейтральным значком; ссылка открывает правильную локализованную категорию, без дверей/скрытых групп, цен и счётчиков.

### SC-004 — Частичный ассортимент

**Covers:** R-004, R-008. **Test level:** Focused integration.

**Given:** Доступна только часть реальных групп фурнитуры.

**When:** Страница показывает ассортимент.

**Then:** Показаны только эти группы; отсутствующие карточки и адреса не создаются.

### SC-005 — Нет доступных категорий

**Covers:** R-002, R-008, R-012. **Test level:** Focused integration для null, пустого и doors-only результата.

**Given:** Категории временно недоступны либо результат не содержит групп фурнитуры.

**When:** Посетитель открывает страницу.

**Then:** Основное предложение, компания, шаги, FAQ, контакты и поисковые сведения сохранены; вместо карточек есть понятное сообщение и переходы в каталог/к менеджеру.

### SC-006 — Факты Class Kedr

**Covers:** R-003. **Test level:** Component + review источников copy.

**Given:** Посетитель оценивает предложение компании.

**When:** Он читает первый экран и блок компании.

**Then:** Он получает сведения об опте/рознице, городе, помощи с подбором и складской программе; наличие и детали закупки уточняются у менеджера, неподтверждённых обещаний нет.

### SC-007 — Подготовить запрос

**Covers:** R-002, R-003. **Test level:** Component.

**Given:** Посетитель хочет начать закупку.

**When:** Он читает порядок работы и ответы на вопросы.

**Then:** Видны три шага и три коротких ответа о связи, данных для запроса и подборе; все ответы доступны без дополнительного раскрытия.

### SC-008 — Локализованная навигация

**Covers:** R-007, R-009. **Test level:** Component href + source существующего language switch.

**Given:** Открыта одна из языковых версий.

**When:** Посетитель выбирает каталог, компанию, доставку, возвраты или другой язык.

**Then:** Переход остаётся в соответствующем разделе и языке; смена языка сохраняет wholesale.

### SC-009 — Темы и ширины

**Covers:** R-010. **Test level:** Source token/breakpoint review; реальная визуальная проверка отдельно.

**Given:** Страница открыта в светлой/тёмной теме при ширине 360, 768 или 1440 px.

**When:** Посетитель читает её и выбирает действие.

**Then:** Порядок, текст и контакты читаются; на телефоне категории в две колонки и шаги вертикальны; горизонтальное прокручивание для основных действий не требуется.

### SC-010 — Клавиатура и семантика

**Covers:** R-011. **Test level:** Component семантики + source focus/skip-link.

**Given:** Посетитель использует клавиатуру или средство чтения.

**When:** Он переходит к основному содержимому, категориям и связи.

**Then:** Заголовки и имена действий понятны, фокус доступен и последователен; основной контейнер и H1 не дублируются.

### SC-011 — Серверное содержание

**Covers:** R-005, R-012. **Test level:** Server component output; HTTP подтверждается отдельно.

**Given:** Каталог доступен и запрошена одна из локалей.

**When:** Получено первоначальное содержимое страницы.

**Then:** H1, введение, категории с переходами, сведения компании, шаги, FAQ и контакты доступны без ожидания клиентской подгрузки.

### SC-012 — Метаданные

**Covers:** R-009, R-012. **Test level:** Unit + source root template; итоговый head отдельно.

**Given:** Запрошена украинская или русская версия.

**When:** Формируется поисковое/социальное представление страницы.

**Then:** Используются принятые уникальные title/description и соответствующая локаль; бренд добавлен один раз.

### SC-013 — Canonical и языки

**Covers:** R-013. **Test level:** Unit builders + source metadataBase; HTTP отдельно.

**Given:** Запрошена действительная версия wholesale.

**When:** Поисковая система читает адресные указания.

**Then:** Canonical ведёт на эту же языковую страницу, обе версии указаны взаимно и общая точка входа — украинская; параметры/якорь не создают отдельную страницу.

### SC-014 — Защита индексации

**Covers:** R-014. **Test level:** Табличный unit с реальной factory конфигурации.

**Given:** Среда production/preview/development использует действующую политику сайта.

**When:** Формируются поисковые указания страницы.

**Then:** Индексация разрешена только при production с явным включением; остальные сочетания закрыты для индексации и следования.

### SC-015 — Хлебные крошки

**Covers:** R-015. **Test level:** Unit + focused server composition/source layout.

**Given:** Открыта одна из локалей wholesale.

**When:** Читается её структурированное описание.

**Then:** Путь Главная → Сотрудничество соответствует видимым крошкам и абсолютным адресам той же локали; новая страница не добавляет вторую организацию или фиктивный товар.

### SC-016 — Карта сайта

**Covers:** R-016. **Test level:** Focused integration sitemap.

**Given:** Сайт формирует карту известных публичных страниц.

**When:** В неё включена страница сотрудничества.

**Then:** UK и RU wholesale присутствуют по одному разу с взаимными языками, без вымышленной даты; прежние content-страницы сохранены.

### SC-017 — Неизвестный язык

**Covers:** R-001, R-009, R-013. **Test level:** Source route/guard integration; фактический HTTP 404 отдельно.

**Given:** Запрошен неподдерживаемый язык страницы, например английский.

**When:** Адрес обрабатывается сайтом.

**Then:** Возвращается страница отсутствующего ресурса со статусом 404, а не украинский indexable fallback; адрес не объявлен языковой версией.

## Незадействованные состояния

Форма, авторизация, запись персональных данных и отправка сообщения отсутствуют. Внешний телефон/мессенджер получает ссылку; успешное открытие стороннего приложения не обещается. Загрузка каталога серверная, отдельный клиентский spinner или skeleton не добавляется. Обычная сетевая недоступность категорий не уничтожает публичную страницу. При неожиданной программной ошибке сохраняется штатная обработка ошибки приложения.
