# Принятый визуальный контракт

## Основание и приоритет

Пользователь принял v2 на 2026-11-03:
[desktop](../../../../../ideas/site-wholesale/concept-v2-desktop-2026-11-03.png),
[mobile](../../../../../ideas/site-wholesale/concept-v2-mobile-2026-11-03.png),
[provenance](../../../../../ideas/site-wholesale/concept-v2-2026-11-03.json).
Это один дизайн в двух темах и двух форматах, не четыре альтернативы.

Приоритет: решение пользователя и [правила](../requirements/behavior.md) → точные [тексты](content.md) и действительная семантика → композиция v2 → растровые детали. Существующие Site header/footer переиспользуются; небольшие особенности их генеративного изображения не становятся поручением переделать оболочку. Сам PNG не импортируется в runtime и не заменяет живой текст/изображения категорий.

## Блоки и путь

| Блок        | Содержание и взаимодействие                                                                                                                               |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hero        | Крошки; единственный товарный H1; lead; основной CTA Telegram и каталог. Справа desktop — контактная панель; на телефоне после действий.                  |
| Ассортимент | Заголовок/короткая подсказка; компактные фото-карточки с названием и стрелкой. Полная поверхность ссылки; без счётчиков/подкатегорий/цен.                 |
| Компания    | Короткий подтверждённый текст, факты опт/розница, город и помощь; два пояснения о подборе и складской программе; переход на локальную главную к компании. |
| Заказ       | Мягкая зелёная полоса: выбрать товары → отправить список → согласовать детали. Никаких обещаний автоматической покупки.                                   |
| FAQ         | Три коротких вопроса и видимых ответа. Не закрытый accordion, новый client state не требуется.                                                            |
| Контакт     | Финальный телефон и Telegram CTA, ссылки доставки/возврата.                                                                                               |
| Shell       | Текущие каркас, header/footer, тема/язык/skip-link; дополнительного main нет.                                                                             |

Основной путь: поисковая выдача → предложение → реальная категория → список товаров → контакт менеджера. Менеджер доступен также сразу с первого экрана.

## Темы, шрифты, форма

[Дизайн-система](../../../../../standards/site/design-system.md) и `apps/site/src/app/global.css` — источник точных значений; raster допускает только приблизительное отображение.

| Роль                            | Light               | Dark                  |
| ------------------------------- | ------------------- | --------------------- |
| Фон / основной текст            | #FFFFFF / #0F110F   | #0C0D0C / #EDEFEA     |
| Вторичная поверхность / граница | #F4F5F2 / #E3E6DF   | #161815 / #242823     |
| Зелёный текст                   | #2A7323             | #7DD06F               |
| Мягкая зелёная поверхность      | #EAF5E7             | #15241A               |
| Основной CTA                    | ink с белым текстом | светлый с ink-текстом |

Бренд #3FA435 остаётся у существующего «Каталог» и акцентов; body text на белом использует brand-text. Onest, Lucide stroke 1.75; кнопки/поля радиус 8 px, панели 10–16 px. Контент до 1440 px, gutters 16 px / от lg 24 px из shell. Новых global tokens, CDN, декоративных изображений и шрифтов нет.

Фотографии — существующие шесть category assets, с `object-contain` и сохранением пропорций; светлая фотоподложка остаётся в обеих темах. Категория без известного фото получает существующий нейтральный значок, без рисованных товаров.

## Адаптивность

| Диапазон    | Наблюдаемая композиция                                                                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 360–767 px  | Hero/действия/контакт последовательно; каталог 2 колонки; названия переносятся; компания не переполняется; шаги вертикальны; FAQ вопрос над ответом; финальный CTA на доступную ширину. |
| 768–1023 px | Категории 2 колонки; остальное допускает более широкие строки, без desktop-контактной боковой колонки до lg.                                                                            |
| От 1024 px  | Hero с контактной панелью справа; категории 3 колонки; шаги горизонтальны; FAQ может располагать вопрос и ответ рядом.                                                                  |

В исходнике проверять 360/768/1440 px как контрольные значения существующих breakpoint rules. Длинные RU-названия/email/телефон не требуют горизонтального скролла. Порядок DOM соответствует чтению, CSS не переставляет смысловые блоки. Обе темы получают те же данные и ссылки.

## Доступность и состояния

Ссылки имеют имена; декоративные иконки/фото внутри уже подписанной category link не дублируют озвучивание. Видимый focus, reduced-motion, корректные heading levels и существующий skip-link сохраняются. Основные ссылки имеют удобную область нажатия не меньше текущей кнопки 40 px; узкие текстовые ссылки остаются обычными ссылками с фокусом.

Если категории недоступны, их место занимает локализованное сообщение и настоящие переходы в каталог/к менеджеру; блоки ниже не исчезают. При частичных данных сетка содержит только действительные группы. Сравнение rendered UI с макетом возможно только после отдельно разрешённой visual/browser проверки; source review не объявляется пиксельным сравнением.
