# 001 — Співпраця: дверна фурнітура оптом

- **Клиент:** публичный Next.js Site, `apps/site`, `E:\RiderProjects\kedr-web`.
- **Домен / вариант:** `content` / `nextjs`.
- **Статус:** implemented и architecture-audited 2026-11-03; AF-001/AF-002 verified, automated/source проверки завершены; build/HTTP/browser/visual unrun.
- **Основание:** пользователь принял концепт v2 сообщением «Окей пиши СДД по етому макету». Затем пользователь явно разрешил реализацию всей СДД сообщением «переходи к релизации по СДД».
- **Владелец продуктовых решений:** владелец Kedr.
- **Продуктовых блокеров:** нет. EN-001 завершена; узкий flow и фактический граф проверены.

Посетитель `/uk/wholesale` или `/ru/wholesale` узнаёт предложение Class Kedr по дверной фурнитуре оптом, переходит к действительным категориям и связывается с менеджером для уточнения цен, наличия и деталей закупки. Страница сохраняет обе локали, темы и общий каркас Site; основное содержание доступно в серверном HTML.

## Принятые решения

1. H1: «Дверна фурнітура оптом» / «Дверная фурнитура оптом»; в меню остаётся «Співпраця» / «Сотрудничество».
2. Подробные условия опта не публикуются. Минимальный заказ, скидки, цены, кратность, сроки и гарантии не придумываются; отсутствие таких сведений не блокирует функцию.
3. Основной CTA открывает существующий Telegram менеджера; телефон и Viber доступны отдельно. Сайт не отправляет сообщение за посетителя.
4. Категории, их имена и URL приходят из существующего каталога. Шесть карточек макета — текущий ассортимент, а не разрешение создавать фиктивные группы при неполном ответе.
5. Факты и контакты берутся из действующих источников Class Kedr. Изобретательность относится к подаче и композиции, не к бизнес-условиям.
6. Общие header/footer, индексационный gate, существующие content-страницы и незакоммиченные изменения сохраняются.
