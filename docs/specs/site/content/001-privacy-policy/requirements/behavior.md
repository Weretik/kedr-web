# Правила и наблюдаемые сценарии

## Правила

- **R-001.** Оба сохранённых адреса показывают язык маршрута: один H1, вступление, крошки «главная → политика», подписи навигации и контактов. Язык и тема независимы.
- **R-002.** Полный документ сохраняет восемь разделов, их порядок, все 15 абзацев и 11 пунктов списков в каждой локали. Резюме не заменяет документ.
- **R-003.** Разрешены только преобразования из [content-source](../design/content-source.md): адрес сайта и контакты из конфигурации, исправление дублирования сказуемого в UK §4.1 и согласованное отображение заголовков. Новых юридических фактов и условий нет.
- **R-004.** До полного текста видны три коротких пункта: собираемые данные, цель и права пользователя. Их смысл подтверждается исходной политикой; точные UI-формулировки находятся в [визуальном контракте](../design/visual.md).
- **R-005.** Восемь пунктов оглавления ведут к уникальным заголовкам соответствующих разделов. Прямой URL с fragment и история переходов работают штатно; заголовок не закрывается шапкой. Подсветка выбранного fragment не означает отслеживание ручной прокрутки.
- **R-006.** На широком экране оглавление доступно сбоку при чтении. Ниже desktop breakpoint оно раскрывается перед резюме. Закрытие оглавления никогда не скрывает сам документ; управление доступно клавиатурой без JavaScript страницы.
- **R-007.** Контакты в §8 и нижнем блоке совпадают с текущей конфигурацией. Основная кнопка открывает email; телефон в полном тексте доступен как телефонная ссылка. Локализованный переход к публичной оферте сохраняется.
- **R-008.** Страница использует существующие шрифты, темы и компоненты оболочки; не вызывает горизонтальной прокрутки на 320–1440 px. Длинные email, H1 и заголовки переносятся. Контраст, видимый focus и иерархия заголовков сохраняются.
- **R-009.** Полный документ, резюме, крошки, контакты и связанные ссылки находятся в исходном серверном HTML и доступны без выполнения JavaScript страницы. Новых сетевых запросов и сбора персональных данных нет.
- **R-010.** Для каждой локали заданы собственные title/description, self canonical, взаимные language alternates и BreadcrumbList по видимым крошкам. Текущий запрет индексации preview/dev сохраняется; Organization не дублируется.
- **R-011.** Sitemap содержит обе страницы с взаимными языковыми связями, сохраняет прежние записи и не получает fragment/query-варианты или вымышленную дату изменения.
- **R-012.** Поддерживаемые адреса доставляют страницу, а неподдерживаемая локаль и неизвестный адрес подчиняются существующей 404-политике. Существующий адрес не переименовывается и не получает новый redirect.

## Сценарии

| ID     | Given / When / Then                                                                                                                                                                                                                                         | Правила      | Минимальное доказательство                                                                               |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| SC-001 | Given один из двух поддерживаемых языков, When посетитель открывает адрес политики, Then H1, вступление, крошки, резюме и навигация показаны на этом языке.                                                                                                 | R-001        | Component, server markup                                                                                 |
| SC-002 | Given исходная политика выбранного языка, When посетитель читает полный документ, Then присутствуют все восемь разделов, 15 абзацев и 11 пунктов списков в исходном порядке.                                                                                | R-002        | Model completeness + component                                                                           |
| SC-003 | Given настроенные адрес сайта и контакты, When документ показан, Then применены только разрешённые подстановки и UK исправление §4.1, а старый домен отсутствует.                                                                                           | R-003        | Pure model unit с отличающимися входными значениями                                                      |
| SC-004 | Given desktop-страница, When посетитель выбирает любой пункт оглавления либо открывает соответствующий fragment напрямую, Then он ведёт к единственному нужному заголовку и сохраняет доступное оглавление; выбор отражает fragment, а не ручную прокрутку. | R-005, R-006 | Component href/target assertions; source CSS/offset review                                               |
| SC-005 | Given узкий экран и закрытое оглавление, When посетитель раскрывает его клавиатурой и выбирает раздел, Then ссылки доступны, а полный документ остаётся видимым независимо от состояния оглавления.                                                         | R-005, R-006 | Component native disclosure semantics + source responsive review; actual browser keyboard check отдельно |
| SC-006 | Given страницу политики, When посетитель читает резюме, Then видит данные, цели и права в кратких формулировках, а полная политика остаётся ниже.                                                                                                           | R-004        | Component                                                                                                |
| SC-007 | Given страницу любой локали, When посетитель выбирает email, телефон либо публичную оферту, Then открывается правильный mailto/tel/локализованный адрес, а видимые контакты совпадают с §8.                                                                 | R-007        | Component links; model bindings                                                                          |
| SC-008 | Given любую локаль и светлую либо тёмную тему, When ширина меняется от телефона до desktop, Then чтение, переносы, focus и порядок блоков сохраняются без горизонтального переполнения.                                                                     | R-001, R-008 | Source theme/breakpoint review; component semantics; browser only if separately authorized               |
| SC-009 | Given отключённый JavaScript страницы, When получен документ, Then весь текст, резюме, ссылки и контакты доступны; загрузка данных, пустой ответ API и ошибка API не требуются.                                                                             | R-009        | Server render component test; HTTP remains separately recorded                                           |
| SC-010 | Given поискового робота или получателя ссылки, When получены metadata любой локали, Then title/description локализованы, canonical self, alternates взаимны и preview/dev остаются закрыты для индексации.                                                  | R-010        | Metadata unit                                                                                            |
| SC-011 | Given существующий sitemap, When добавлена политика, Then обе локали включены однократно с взаимными alternates, прежние записи сохранены, fragments/query и вымышленная lastModified отсутствуют.                                                          | R-011        | Sitemap unit                                                                                             |
| SC-012 | Given неподдерживаемую локаль либо неизвестный адрес, When запрошен такой адрес, Then применяется существующая 404-политика вместо ложной страницы политики.                                                                                                | R-012        | Route guard source review + narrow typecheck; HTTP/E2E unrun without separate authorization              |
| SC-013 | Given видимые крошки «главная → политика», When разобрана структурированная разметка страницы, Then BreadcrumbList содержит те же имена, адреса и порядок, а Organization остаётся только у layout.                                                         | R-010        | JSON-LD unit + server markup                                                                             |

Визуальные и HTTP-проверки не объявляются выполненными на основании jsdom или анализа классов. Результаты реализации и границы доказательств фиксируются в задачах и [SEO-журнале](../verification/seo-verification.md).
