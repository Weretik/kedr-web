# Межі та результат

Входять `/{locale}/articles`, URL-пошук/пагінація, `/{locale}/articles/{slug}`, обидві локалі, теми, server HTML, metadata, BreadcrumbList/Article, sitemap та 301 зі старих ID 1–6. Видимий label перед пошуком відсутній.

Джерело: шість локалізованих матеріалів і обкладинок чинного Angular storefront; це дозволений тимчасовий перенос, не нові рекламні тексти. Пошук охоплює назву і повний текст поточної локалі. Порядок матеріалів зберігається.

Не входять backend, адмінка, CMS/MDX, редагування текстів, категорійні фільтри, сортування, коментарі, підписка, новий глобальний shell, публікація чи переключення домену. Відсутні author/dateModified не вигадуються. Подальша БД/API-міграція — окреме завдання.

Готовність: усі сценарії та focused checks пройдені; невиконані browser/build/HTTP checks названі явно. Нового дозволу між SDD та реалізацією не потрібно: обидва етапи вже доручені.
