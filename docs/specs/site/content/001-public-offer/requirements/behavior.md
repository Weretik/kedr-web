# Rules and scenarios

## Rules

- **R-001 — Entry and language.** Both existing localized URLs display one localized short H1, original full title and home breadcrumb. The language switch keeps the public-offer page path; preserving its current hash or scroll position is not required.
- **R-002 — Source integrity.** The seven complete source sections, 18 numbered paragraphs and final unnumbered note remain in order in both languages. No legal paraphrase, fabricated revision date, seller or payment details.
- **R-003 — Desktop wayfinding.** At wide viewports contents is a sticky left rail, document is a readable right column. Seven real anchors target unique sections below the sticky store header. Current section is highlighted when browser enhancement is available.
- **R-004 — Narrow layout.** On phones/tablets contents is a native disclosure closed initially. Only contents collapses; all contract paragraphs stay open in a single reading column.
- **R-005 — Progressive access.** The complete document and section links are available without JavaScript. Keyboard access, visible focus, semantic headings and reduced-motion preference are respected. Missing observer support does not break anchors or hide the document.
- **R-006 — Print.** The print action invokes the browser print dialog. Printed output includes title, all seven sections, 18 paragraphs and final note once, in black on white, without shop navigation, contents, contact CTA or interactive controls. No PDF service or success confirmation is implied.
- **R-007 — Contact and related pages.** Phone/email come from current company configuration; call and email links use matching destinations. Related links lead to the same-language delivery/returns pages. Old duplicate privacy-card/self-link UI is not recreated.
- **R-008 — Theme and frame.** Existing shell, fonts, tokens and gutters remain. Layout stays readable without horizontal overflow at narrow widths or with longer Russian labels. Print styling cannot affect another page.
- **R-009 — Public discovery.** Metadata is localized, canonical is self, language alternates are reciprocal, visible breadcrumbs match structured data, and sitemap includes both canonical page URLs exactly once.
- **R-010 — Existing policy.** Preview indexing remains off under the existing gate; production indexability follows that gate. Unsupported locales retain existing not-found behavior. No invented modification date, query URL, hash or duplicate page is advertised as a canonical sitemap entry.
