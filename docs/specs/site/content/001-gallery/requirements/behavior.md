# Правила и приёмочные сценарии

## Правила

| ID    | Правило                                                                                                                                                                                                                                                                       |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-001 | Галерея доступна без входа по прежнему локализованному адресу; тема — дверная фурнитура.                                                                                                                                                                                      |
| R-002 | Публикуются только подтверждённые реальные медиа и переводы. Стабильный ID и явный редакционный порядок не зависят от формата или выдуманной популярности.                                                                                                                    |
| R-003 | Общая композиция A: крупный первый материал, до двух вторичных, затем регулярная смешанная сетка. Материал не дублируется между блоками. Неполный ряд адаптируется к наличию контента.                                                                                        |
| R-004 | «Усі / Фото / Відео» фильтрует единую коллекцию, сохраняет относительный порядок и не меняет URL/history.                                                                                                                                                                     |
| R-005 | Начальный набор — до семи материалов: три в верхней композиции и четыре ниже. «Показати ще» раскрывает до четырёх следующих; кнопки нет, если больше материалов нет. Смена фильтра возвращает начальный объём.                                                                |
| R-006 | Фото открывается крупно с названием, подписью, закрытием и переходами в текущей отфильтрованной коллекции. На её концах соответствующий переход недоступен; циклической прокрутки нет.                                                                                        |
| R-007 | Видео загружается в player только после выбора пользователем. Автовоспроизведение отсутствует, закрытие/смена материала удаляет проигрыватель.                                                                                                                                |
| R-008 | Ошибки не уничтожают подпись и управление. Для видео всегда доступна ссылка на оригинал и повтор загрузки player; недоступность внешнего провайдера не маскируется обещанием автоматического обнаружения.                                                                     |
| R-009 | Управление доступно с клавиатуры, имеет имена, заметный фокус, корректный dialog и возврат фокуса; motion учитывает reduced-motion.                                                                                                                                           |
| R-010 | UK/RU, существующие light/dark-темы и адаптивность обязательны; бизнес-факты не смешиваются с переводимыми подписями.                                                                                                                                                         |
| R-011 | Основное содержание и ссылки доступны в исходном HTML. Metadata, canonical, alternates и BreadcrumbList принадлежат domain SEO; gallery добавляется в sitemap без выдуманных дат.                                                                                             |
| R-012 | По уточнению пользователя первый этап содержит все семь публичных видео канала Kedr Class. Фотоформат поддерживается; фотографии и подписи добавляются следующим этапом только из реальных подтверждённых источников. Пустой фотофильтр не заполняется фиктивными карточками. |

## Сценарии

Технические владельцы, пути и проверки намеренно вынесены в [design](../design/frontend.md) и [задачи](../tasks/README.md).

### SC-001 — Открытие общей коллекции

**Given** посетителю доступна подтверждённая смешанная коллекция в редакционном порядке. **When** он открывает галерею. **Then** выбран режим «Усі», первый материал крупный, следующие два вторичные, остальные идут ниже без дублей; видны не более семи материалов, названия и форматы различимы. Покрывает R-001…R-003, R-005.

### SC-002 — Фильтр формата

**Given** посетитель просматривает коллекцию, включая дополнительно раскрытые материалы. **When** он выбирает «Фото», «Відео» или «Усі». **Then** остаются подходящие материалы в прежнем относительном порядке, начальный объём восстанавливается, активный выбор заметен, адрес и история не меняются. Покрывает R-004, R-005.

### SC-003 — Дополнительные материалы

**Given** подходящих материалов больше начального набора. **When** посетитель нажимает «Показати ще». **Then** добавляются до четырёх следующих без дублей и перемещения прежних; после последней порции кнопка исчезает, доступно сообщение о добавленном количестве. Покрывает R-002, R-005, R-009.

### SC-004 — Пустой формат

**Given** в доступном наборе нет фотографий. **When** посетитель выбирает «Фото». **Then** видит сообщение и «Показати все», без фиктивных фото и выдуманного счётчика; сброс возвращает реальные материалы. Это поддерживаемое деградированное состояние, а не приёмка полного выпуска. Покрывает R-004, R-008, R-012.

### SC-005 — Просмотр фото и переходы

**Given** посетитель выбрал фотографию. **When** он открывает её и нажимает предыдущую/следующую. **Then** видит выбранный материал, название, доступную подпись и фактическую позицию в текущей отфильтрованной коллекции, включая ещё не раскрытые карточки; переход на концах недоступен. Фото целиком помещается в область просмотра без обрезания важных деталей. Покрывает R-006.

### SC-006 — Клавиатура и закрытие

**Given** фото открыто крупно. **When** посетитель использует Tab, стрелки, Escape или явное закрытие. **Then** фокус остаётся внутри открытого просмотра, стрелки переключают материалы текущей отфильтрованной коллекции; при переходе на видео player ожидает запуска пользователем. Escape/закрытие возвращает фокус на исходную карточку, скрытый фон недоступен для фокуса. Стрелки не перехватываются у внешнего player. Покрывает R-006, R-007, R-009.

### SC-007 — Видео по явному выбору

**Given** страница загружена, но посетитель ещё не выбирал видео. **When** он выбирает видеокарточку. **Then** только теперь открывается player с локализованным названием; он ожидает запуска стандартным контролом. До выбора player и его внешние скрипты отсутствуют. Закрытие или переход к другому материалу прекращает прежний просмотр. Покрывает R-007.

### SC-008 — Недоступный внешний ролик

**Given** внешний сервис не воспроизводит выбранное видео. **When** посетитель остаётся в просмотре. **Then** сохраняются название, закрытие, повтор и ссылка на оригинал. Повтор заново загружает только выбранный player; автоматического воспроизведения нет. Нельзя требовать достоверного определения всех ошибок чужого сервиса по одному событию загрузки. Покрывает R-007, R-008.

### SC-009 — Изображение не загрузилось

**Given** фото или постер недоступен. **When** возникает ошибка загрузки. **Then** сохраняются место изображения, подпись и формат; виден нейтральный placeholder и повтор. Видео с повреждённым постером остаётся доступно для явного выбора, ошибка фото в viewer не блокирует закрытие или переход. Покрывает R-008, R-009.

### SC-010 — Язык

**Given** посетитель находится на галерее в UK или RU. **When** он переключает язык существующим контролом сайта. **Then** остаётся на галерее другой локали с её заголовком, фильтрами, названиями, alt и сообщениями. Воспроизведение прекращается; начальное состояние фильтра и раскрытия восстанавливается. Покрывает R-010.

### SC-011 — Темы и узкий экран

**Given** посетитель использует light/dark и узкий либо широкий экран. **When** просматривает коллекцию и открытый материал. **Then** подписи и управление читаемы, не выходят за экран, фокус виден, фото не обрезано, viewer можно закрыть; существующая оболочка не меняет состава. Покрывает R-003, R-009, R-010.

### SC-012 — Исходный HTML и базовые ссылки

**Given** JavaScript ещё не выполнился либо отключён. **When** посетитель или crawler получает галерею. **Then** заголовок, ввод, названия и обычные ссылки начальных материалов уже доступны; оставшиеся материалы доступны через базовый список без JavaScript. Фото ведёт к реальному изображению, видео — к оригиналу. Интерактивное улучшение не создаёт пустую стартовую страницу. Покрывает R-011.

### SC-013 — Целостность данных

**Given** подготовлен набор к публикации. **When** проверяются ID, локали, исходники, размеры и порядок. **Then** ID уникальны, оба перевода заполнены, фото/постеры имеют реальные положительные размеры и локальные пути, видео использует допустимый ID, неизвестные даты/длительности отсутствуют. Некорректная запись не становится произвольным встроенным URL или молчаливым частичным переводом. Покрывает R-002, R-008, R-010.

### SC-014 — Согласованный первый контентный этап

**Given** владелец подтвердил все видео канала и отложил фотографии. **When** оценивается готовность первого этапа. **Then** он содержит все семь подтверждённых публичных видео и работает без фиктивных фото; фотофильтр показывает пустое состояние, а реальные фотографии можно добавить в ту же коллекцию следующим этапом. Сгенерированные примеры концепта не становятся товарными фотографиями. Покрывает R-002, R-012.

### SC-015 — Локализованная ссылка для поиска и sharing

**Given** crawler или сервис sharing открывает UK/RU галерею. **When** читает её описание. **Then** title содержит бренд один раз, description соответствует реальному составу, canonical указывает на эту же локаль, alternates взаимны, x-default ведёт на UK; состояния фильтра/viewer не образуют новых страниц. Покрывает R-011.

### SC-016 — Индексация окружения

**Given** окружение не production либо production не включило индексацию. **When** запрашивается галерея. **Then** действует существующий noindex/nofollow; только общий production opt-in разрешает индексацию. Само добавление галереи не меняет этот gate. Покрывает R-011.

### SC-017 — Крошки и sitemap

**Given** каноническая галерея добавлена в публичные страницы. **When** проверяются крошки и sitemap. **Then** крошки содержат главную и галерею текущей локали, sitemap имеет одну запись галереи на каждую локаль с взаимными alternates, без даты из даты разработки, параметров фильтра и отдельных viewer URL; прежние страницы сохранены. Покрывает R-011.

### SC-018 — Стабильный публичный адрес

**Given** посетитель переходит по существующей ссылке галереи. **When** он открывает UK/RU адрес либо адрес с неподдерживаемой локалью. **Then** прежний /galleria работает без нового slug/redirect, а неподдерживаемая локаль получает существующее поведение 404 вместо незаметной подмены языка. Покрывает R-001, R-010, R-011.
