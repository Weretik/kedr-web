# Архитектурный аудит — галерея Site

- **Дата:** 2026-11-03.
- **Объём:** внедрённая галерея `/uk/galleria`, `/ru/galleria`; её пять content-слоёв, route, общий Dialog, непосредственные core dependencies и средства проверки. Другие content-функции и весь репозиторий не аудировались.
- **Основание:** пользователь прямо запросил аудит, исправления и разделение компонентов со смешанными ответственностями.
- **Ответственный:** основной агент, с независимыми read-only обзорами UI и model/data-access; результат интегрирован основным агентом.
- **Статус:** verified в указанном объёме. Medium: 1 verified; low: 2 verified; открытых находок нет. Новых продуктовых решений или системной remediation SDD не требуется.
- **Задача исправлений и подробные команды:** [TS-008](../tasks/TS-008-architecture-audit.md#evidence).

## Матрица архитектуры и фактический поток

| Проект                                                | Владелец ответственности                                      | Фактические разрешённые связи галереи               | Результат                                                                      |
| ----------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------ |
| `site`                                                | params/isLocale/notFound, один вызов feature, metadata export | content/feature, content/seo, core/i18n             | Тонкий route, без source mapping или client state                              |
| `site-content-feature`                                | Серверная композиция, locale binding, noscript, JSON-LD       | content/{data-access,model,ui,seo}, core/{i18n,seo} | Серверный владелец страницы                                                    |
| `site-content-data-access`                            | Curated authoring, validation и locale mapping                | content/model, type-only core/i18n                  | `server-only`, наружу только `getGalleryMedia`; AF-001 относится к test inputs |
| `site-content-model`                                  | Readonly media union, чистые фильтр/порции, словарь           | type-only core/i18n                                 | Без React, I/O и transport                                                     |
| `site-content-ui`                                     | Отображение и локальные интерактивные жизненные циклы         | content/model, core/i18n, shared/ui                 | Не импортирует data-access/feature/source                                      |
| `site-content-seo`                                    | Metadata/BreadcrumbList builders                              | Только core/{config,i18n,seo}                       | Особый core-only allowlist соблюдён                                            |
| `site-shared-ui`                                      | Нейтральные Button/Dialog primitives                          | В gallery Dialog нет domain imports                 | Radix владеет focus containment и scroll lock                                  |
| `site-core-config`, `site-core-i18n`, `site-core-seo` | Существующие конфигурация, локаль и SEO API                   | Потребляются через public indexes                   | Нет обратной зависимости к галерее                                             |

Source → validation → immutable выбранная локаль → server feature → client gallery props. Bilingual authoring и внутренние validator/mapper не экспортируются. HTTP/API/CMS/OpenAPI операции отсутствуют по принятому scope; параллельного транспорта, query cache или ручного server-data lifecycle нет. Static literal source требует rebuild; runtime caching API для него не добавлен. Route и SEO остаются серверными; client entry — связная галерея с props, без импорта server source.

Проверка AST/aliases по текущим правилам охватила 18 production-файлов, 18 уникальных разрешённых project edges и относительные внутренние импорты. Циклов в проверенной локальной цепочке и утечек private exports не обнаружено. Проверены отрицательные направления UI → data-access, model → feature, data-access → app, SEO → model/data-access и core SEO → domain: все шесть отклоняются сочетанием действующих ESLint constraints и project-boundary validator. `next/link` в серверном header разрешён правилами Site; Admin-only запрет router imports сюда не переносится.

## Решения о разделении и структуре

Количество относится к production-файлам галереи, а не ко всем соседним content-функциям. Правила Site не задают числового порога размера; отдельные слои, hooks и папки без независимой ответственности не добавлялись.

| Область / количество                                   | Решение       | Владелец и причина                                                                                                                                                                                      |
| ------------------------------------------------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content/model/src/lib/gallery/` / 3                   | keep          | Types, UI copy и чистые операции уже разделены по ролям; один media contract.                                                                                                                           |
| `content/data-access/src/lib/gallery{,-source}.ts` / 2 | keep          | Authoring отделён от подготовки данных. Validation и mapper образуют одну серверную границу, не имеют независимых запросов или side effects; публичен только getter.                                    |
| `content/ui/src/lib/gallery/` / 8                      | keep          | Одна media collection; независимые жизненные циклы уже вынесены в отдельные компоненты.                                                                                                                 |
| `GalleryBrowser` / `GalleryCollection`                 | keep          | Один согласованный session: filter, portion, active ID и исходный trigger. [SDD](../design/frontend.md#владельцы-и-поток) прямо назначает ему эту роль. Здесь нет HTTP, image recovery или JSX диалога. |
| `MediaViewer`                                          | keep          | Один controlled dialog: текущий материал, позиция, bounded navigation, keyboard adapter и возврат фокуса. Его header/body/footer не имеют самостоятельных циклов.                                       |
| `MediaImage`, `VideoFrame`                             | keep отдельно | Изображение владеет loading/error/retry; player владеет iframe identity/reload/recovery. Эти состояния не перенесены в Browser.                                                                         |
| Header / filters / grid / card                         | keep отдельно | Серверный heading, выбор формата, композиция карточек и native/enhanced activation имеют отдельные контракты.                                                                                           |
| `shared/ui/dialog.tsx` / 1                             | keep          | Доменно независимый Radix wrapper; тексты через props, без gallery navigation или source logic.                                                                                                         |
| Route / server page / SEO builders / 1+1+2             | keep          | Уже разделены маршрутизация, серверная композиция и SEO ownership; циклов или обратных импортов нет.                                                                                                    |

Смешанных независимых потоков, требующих дополнительного splitting, не обнаружено. Поведение, семантика markup, дизайн и публичные API сохранены.

## Проверка и ограничения

[TS-008 Evidence](../tasks/TS-008-architecture-audit.md#evidence) фиксирует применимые проверки и исходные ошибки до исправления. После исправлений подтверждены target inputs/affected/hash plan, текущие разрешённые и запрещённые импорты, source target без кеша, lint исправленных файлов и локальные document links/diff. Все три AF переведены в verified только после соответствующей проверки.

Предыдущие 112 scenario cases и проверки app/spec типов остаются историческими evidence первоначальной реализации; заново весь этот набор не запускался. Изменения runtime ограничены whitespace в двух файлах, поэтому отдельные поведенческие tests и typegen не добавлялись. Browser/manual/visual/E2E, production build, live HTTP/head, CWV, доступность реального YouTube playback и отдельный SEO audit не входят в этот архитектурный аудит. Публикация/commit/push не выполнялись.
