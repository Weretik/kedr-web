# UI-фаза Next.js Site

Это навигация по одному выбранному Next.js-варианту, не отдельная реализационная задача. [TS-004](TS-004-cart-drawer.md) отвечает за drawer и строки; [TS-005](TS-005-checkout-view.md) — за форму, итог и визуальные состояния; [TS-009](TS-009-app-cart-composition.md) связывает их с реальными producer/consumers. Источник — [принятый визуальный дизайн](../design/visual.md).

Проверять компоненты, локали, tokens и breakpoint source; browser/visual/manual только после отдельного прямого разрешения. Прототип с demo data не переносится как production transport.
