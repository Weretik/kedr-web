# SEO-фаза приватного checkout

Все SEO требования выполняет [TS-008](TS-008-checkout-route-seo.md); [TS-010](TS-010-verification-and-docs.md) собирает evidence. [SEO design](../design/seo.md) и [план проверки](../verification/seo-verification.md) сохраняют checkout noindex, existing robots disallow и исключение из sitemap. Эта фаза не добавляет новых task IDs и не запускает build/HTTP/browser по умолчанию.
