# API and data rules

## Contracts and DTOs

- The canonical machine-readable contract in the frontend is a versioned snapshot under `docs/contracts/openapi/`, synchronized from a pinned backend commit.
- Request, response, and schema types are generated by the CLI command `npm run contracts:generate` into `@shared/api-contracts`; handwritten copies of the same transport shapes are prohibited.
- Generated types are allowed only in transport, auth adapters, or domain `data-access`. Features, UI, and domain models receive their own model through a mapper.
- Generated TypeScript checks compile-time compatibility, but does not replace runtime validation for external/unknown responses.
- Each consumed operation must have a stable `operationId` and a short consumer projection under `docs/contracts/<module>/` describing mapping, behavior, and limitations.

- Public API routes, query parameters, and response fields are stable by default; a breaking change requires a contract, migration path, and rollout in the feature spec.
- Refer to the versioned OpenAPI snapshot before implementing client code.
- DTOs, transport envelopes, and runtime response parsing remain private in `data-access/contracts`.
- A mapper converts DTOs to a domain/view model at the API boundary; `ui` and `feature` do not work with DTOs.
- Do not show users raw transport errors, stack traces, or internal details.

## Requests and state

- Admin and Mobile use the existing RTK Query `baseApi`, injected endpoints, and typed hooks. Axios belongs to the relevant shared API client; raw Axios in `admin/core/auth` is allowed only for session bootstrap/refresh per `docs/architecture/admin/adr/0001-admin-axios-transport.md`.
- Storefront uses Angular `HttpClient` in `data-access`, a repository/facade, and signals/RxJS. RTK Query does not apply to Storefront.
- Components and presentation `ui` in any client must not call HTTP/API directly.
- Pass cancellation signals to the transport and preserve existing error normalization.
- Define pagination, filtering, sorting, and cache/refetch semantics in the contract before coding.
- Do not duplicate RTK Query cache, loading, or error state in a feature reducer or component state. For Storefront, do not duplicate resource/observable server state outside its data-access facade.
- `fetch` in `libs/shared/logging` is allowed only as a best-effort fallback after `sendBeacon`; it is not API/server-state transport and must not be used by domain queries/mutations.

## Public configuration

- Validate public runtime configuration at the application boundary.
- Do not put secrets, tokens, PII, or request/response bodies in source, logs, or docs.
