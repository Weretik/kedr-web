## Граница предложения

Рабочее предложение — общая страница выбора направления. В существующей навигации «Регионы» открывает меню из 23 ссылок: 22 области и отдельный Киев. Киев и Киевская область остаются разными направлениями. Это региональные страницы продаж дверной фурнитуры; подтверждённых региональных офисов и пунктов выдачи в источниках нет.

Новый адрес общей страницы не назначен. В плане миграции остаётся решение владельца: сохранить 23 посадочные страницы с уникальным содержанием или объединить их в страницу доставки. Этот концепт показывает композицию общего указателя и сам по себе не меняет SEO-политику, маршруты и существующие ссылки.

Результат этой задачи — изображение и описание. Код приложения, маршруты, глобальные стили и существующая документация не менялись. Это ещё не готовая спецификация для реализации.

## Что показано в макете

Четыре варианта: desktop UK light, desktop RU dark, mobile UK light и mobile RU dark. Обе локали должны поддерживать обе темы: расположение вариантов на доске не связывает язык с темой.

На desktop видна полная композиция. На мобильных вариантах показана верхняя часть страницы: список продолжается прокруткой, а порядок заказа и контакт находятся ниже. Это не сокращённый мобильный набор направлений.

1. Существующие шапка сайта, хлебные крошки, заголовок «Регіони» / «Регионы» и короткое вступление.
2. Якорные ссылки на выбор региона, порядок заказа и условия доставки.
3. Основной блок «Оберіть свій регіон» / «Выберите свой регион»: отдельный поиск по региону, число направлений и простые ссылки. На desktop — три колонки; на телефоне — одна.
4. Спокойная акцентная полоса из трёх шагов: выбрать товары, согласовать заказ, согласовать доставку.
5. Условия доставки без обещаний цены и срока; ссылка на существующую информационную страницу.
6. Компактная панель помощи с телефоном (068) 713-50-49 и действием звонка.
7. Существующий SiteFooter. В растровом макете ссылки сокращены для композиции; при реализации использовать полный действующий footer, включая юридические ссылки.

Все 23 направления в изображении сверены с текущим REGION_SLUGS и UK/RU словарём shell. Контактный email: kedr.class19@gmail.com — из COMPANY.

## Основной путь пользователя

Пользователь просматривает список или находит область по названию, затем открывает соответствующую региональную страницу в текущей локали. Из неё продолжает к каталогу и согласованию заказа. Из общей страницы также доступны условия доставки и звонок менеджеру.

Предложенный поиск по регионам отделён от глобального поиска товаров в шапке. Он фильтрует уже доступный список и не требует нового API. Названия направлений и ссылки должны присутствовать в исходном серверном HTML; без JavaScript остаётся полный список.

Подсветка Киева в макете — пример наведения или клавиатурного фокуса. Она не выбирает адрес доставки, не пересчитывает стоимость и не сохраняет регион автоматически.

## Состояния и взаимодействия для последующей спецификации

| Состояние        | Предлагаемое поведение                                                                |
| ---------------- | ------------------------------------------------------------------------------------- |
| Начальное        | Все 23 направления, ни одно не выбрано автоматически                                  |
| Поиск            | Фильтр по локализованному названию, без учёта регистра; отображается число совпадений |
| Нет совпадений   | «Регіон не знайдено» / «Регион не найден», действие очистки и доступ к менеджеру      |
| Очистка          | Возвращаются все 23 ссылки, фокус остаётся в поле                                     |
| Клавиатура       | Доступные подписи, видимый focus ring; Enter открывает ссылку с фокусом               |
| Длинное название | «Івано-Франківська область» переносится; стрелка и зона нажатия сохраняются           |
| Телефон          | Одна колонка, зоны нажатия не менее 44 px, нижние блоки следуют по вертикали          |
| UK/RU и тема     | Одинаковый состав направлений и секций; текущие переключатели shell                   |
| Без JavaScript   | Полный список обычных ссылок и остальные основные действия доступны                   |

Поскольку данные статические, отдельные сетевые loading/error состояния здесь не предлагаются. Поведение неизвестного slug должно быть определено в SEO-части будущего SDD перед реализацией.

## Визуальные правила

Источник — текущая дизайн-система и ближайший информационный экран возвратов, а скриншот пользователя служит референсом композиции.

- Onest; H1 около 36 px desktop / 30 px mobile. Контент ограничен 1440 px, поля 16 px и 24 px от lg.
- Фон light #FFFFFF, текст #0F110F, muted #F4F5F2, границы #E3E6DF.
- Фон dark #0C0D0C, текст #EDEFEA, панели #111311, muted #161815, границы #242823.
- Зелёные ссылки: brand-text #2A7323 / #7DD06F. Фирменная заливка #3FA435 с белыми короткими подписями и цифрами.
- Основное действие звонка: ink с белым текстом в light; светлая заливка с тёмным текстом в dark. «Каталог» остаётся зелёным.
- Радиусы 8 px у полей и кнопок, около 14 px у панелей; тонкие границы, сдержанные поверхности. Иконки Lucide stroke 1.75.
- При реализации использовать реальные компоненты shell, логотип и токены. Растровая генерация показывает направление; точные начертания, оттенки, тексты и полный состав shell берутся из исходников.

## Проверка и следующий шаг

Независимые агенты проверили смысл региональных страниц и соответствие текущим UI-паттернам. Основной агент интегрировал результаты, проверил четыре изображения и исправил основные кнопки, год и цвет чисел шагов.

Растровый концепт создан встроенным image_gen; точные промпты сохранены рядом. Приложение и браузер не запускались, автоматические тесты для концепта не требуются.

Перед реализацией нужна обратная связь по структуре общего указателя. Затем следует зафиксировать тип страницы и SEO-решение в SDD, определить маршрут и сценарии поиска. Реализация в apps/site не входит в эту задачу.
