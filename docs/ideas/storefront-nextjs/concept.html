Нова вітрина ClassKedr

Макет у стилі shadcn/ui для Next.js: головна, каталог, товар і кошик. Категорії й контакти з поточного сайту; товари, ціни та фото умовні, на сайті будуть реальні.

Спробуйте: «Каталог» у шапці, фільтри, вигляд «таблиця», «У кошик».

Як це буде зроблено

Стек

  • Next.js App Router, новий застосунок apps/site у kedr-web; Angular-вітрина працює до перемикання.
  • shadcn/ui на Radix: Navigation Menu (каталог), Sheet (фільтри на телефоні), Checkbox, Switch, Tabs, Select, Sonner.
  • Tailwind CSS v4; кольори бренду як CSS-змінні теми shadcn, світла й темна теми.
  • Дані з OpenAPI-контракту KedrStore через api.classkedr.com.ua.

Рендеринг

  • Головна, категорії, товари, статті, регіони: серверний рендер із кешем (ISR), повний HTML для Google.
  • Зараз сторінка товару рендериться лише в браузері, тож пошуковик бачить порожній шаблон.
  • Кошик, оформлення, кабінет: клієнтська частина, noindex.

SEO

  • title, description, canonical, Open Graph; hreflang uk/ru.
  • sitemap.ts, robots.ts, JSON-LD: Organization, BreadcrumbList, Product + Offer, ItemList.
  • Фільтри: одне покриття індексується як посадкова, комбінації, сортування й вигляд таблицею ведуть canonical на категорію. Поточні URL зберігаємо.
  1. SDD (nextjs + SEO) і дизайн-система
  2. Каркас: шапка, підвал, теми, мови, клієнт API
  3. Каталог: фільтри, таблиця, фасетні URL
  4. Сторінка товару з JSON-LD
  5. Кошик і швидке замовлення
  6. Статті, сторінки компанії, регіони, співпраця
  7. Sitemap, robots, редиректи, SEO-аудит
  8. Перемикання домену й аудит структури коду
