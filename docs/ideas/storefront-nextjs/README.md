# Новая витрина на Next.js

**Статус:** идея и план, не принятое решение. Записано 2026-10-26 по обсуждению с владельцем продукта. Кода нет. Перед реализацией идею нужно оформить как SDD по [правилам поставки](../../standards/shared/delivery-rules.md) в варианте `nextjs` с обязательным SEO-дизайном.

Макет: [concept.html](concept.html) (откройте файл в браузере) и [опубликованная версия](https://claude.ai/artifact/3JXo66ncDpjKYJVm9RHq1i). В макете показаны четыре страницы: главная, каталог, товар и корзина. Есть светлая и тёмная темы. Категории, контакты и пункты шапки взяты с текущего сайта. Товары, цены и места под фото условные.

## Цель

Полностью пересобрать публичную витрину ClassKedr (сейчас `apps/storefront` на Angular) на React + Next.js. Нужен современный лаконичный дизайн и сильное SEO.

Бизнес-рамки:

- **Только продажа дверной фурнитуры.** Основной канал — опт, с возможностью розничного заказа. Без услуг, ремонта, врезки и подбора по вырезу.
- В шапке остаётся всё, что есть сейчас, в новом виде (см. ниже).

## Дизайн

Выбран один вариант в стиле shadcn/ui: «минимум цветов, просто и лаконично». Первые три варианта («Майстер», «Антрацит», «Пагін») отклонены как грубоватые; текущий собран на основе «Майстра».

### Принципы

- **Главное — товар, цена и наличие.** Цвет только там, что нужно нажать или заметить.
- **Брендовые цвета:** зелёный логотипа `#3FA435` и почти чёрный `#0F110F`.
- **Основные кнопки** почти чёрные (в тёмной теме светлые). Зелёный только в акцентах: логотип, «Каталог», «Стати партнером», «Співпраця», наличие, счётчик корзины.
- **Нейтральные цвета** с лёгким зелёным оттенком: фон `#FFFFFF`, приглушённый `#F4F5F2`, граница `#E3E6DF`, вторичный текст `#5C6459`. В тёмной теме: фон `#0C0D0C`, приглушённый `#161815`, граница `#242823`, текст `#EDEFEA`.
- **Шрифты:** Onest (украинский шрифт с кириллицей) для всего интерфейса, JetBrains Mono только для артикулов.
- **Радиусы:** 8 px у полей и кнопок, 10–16 px у карточек и блоков.
- **Иконки:** одна линейная система (lucide в shadcn/ui), толщина линии 1,75.
- **Анимация** сдержанная: мега-меню плавно выпадает, кнопка «У кошик» на секунду становится «Додано», счётчик корзины подпрыгивает. С учётом `prefers-reduced-motion`.
- **Фото** реальные, на однородном светлом фоне. Без фото место показывает нейтральную плашку с иконкой категории. Рисованные товары не используем.

### Шапка

1. **Верхняя строка:** «Україна, м. Харків», «Про компанію», «Доставка та оплата», «Повернення та обмін», «Галерея та відео», «Статті», «Контакти», переключатель UA/RU, тема.
2. **Основная строка:** логотип, кнопка «Каталог» с мега-меню, поиск по артикулу или названию (горячая клавиша `/`), телефон (068) 713-50-49 с копированием, Telegram, Viber, «Кабінет», корзина с суммой и количеством. Шапка закреплена при прокрутке.
3. **Строка категорий:** Завіси, Замки, Ручки, Циліндри, Міжкімнатні механізми, Інше, Двері, «Регіони», «Співпраця».
4. **Мега-меню:** все разделы с подкатегориями, двери по брендам и блок «Оптовим партнерам».
5. **На телефоне:** поиск отдельной строкой, телефон, кабинет и корзина иконками.

### Страницы

- **Главная.** Первый экран с заголовком «Дверна фурнітура оптом і в роздріб» и поиском по артикулу с подсказками частых запросов. Рядом тёмный блок «Оптовим партнерам»: гибкие цены, объёмы под запрос, резерв на складе, связь с менеджером. Ниже указатель каталога: шесть разделов с подкатегориями ссылками, что полезно для перелинковки. Затем популярные позиции и три факта («Завжди на складі», «Оптом і в роздріб», «Доставка по Україні»), в конце подвал.
- **Каталог.** Хлебные крошки, заголовок, подкатегории кнопками. Фильтры: покрытие, «Тільки в наявності», цена. Сортировка и переключатель вида «плитка / таблица». Таблица сделана для опта: фото, артикул, название, наличие, цена, количество и «У кошик» в одной строке. Для пустого результата есть состояние со сбросом фильтров.
- **Товар.** Галерея с миниатюрами, артикул, наличие, название. Блок покупки: розничная цена, строка «Оптова ціна доступна партнерам» со входом в кабинет, выбор покрытия, количество, «У кошик» и «Купити в 1 клік». Ниже доставка, оплата и возврат, вкладки «Характеристики / Опис / Доставка та оплата», блок «З цим купують».
- **Корзина.** Позиции с количеством и удалением. Итог и два режима: «Швидке замовлення» (имя и телефон) или «Повне оформлення» (плюс Нова пошта). Для пустой корзины есть своё состояние.

## Технологии

| Слой      | Выбор                                                                                                                                                            |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Фреймворк | Next.js App Router, новое приложение `apps/site` в Nx-монорепо kedr-web. Angular-витрина работает до переключения домена.                                        |
| UI        | shadcn/ui на Radix UI: Navigation Menu (каталог), Sheet (фильтры и меню на телефоне), Checkbox, Switch, Select, Tabs, Sonner (уведомления).                      |
| Стили     | Tailwind CSS v4. Цвета бренда как CSS-переменные темы shadcn, тёмная тема через класс `dark`.                                                                    |
| Данные    | Типизированный клиент из OpenAPI-контракта KedrStore, запросы из серверных компонентов к `api.classkedr.com.ua`.                                                 |
| Рендеринг | Главная, категории, товары, статьи, регионы: серверный рендер с кешем и ревалидацией по тегам (ISR). Корзина, оформление и кабинет: клиентская часть, `noindex`. |

## SEO

Опирается на скилы плагина `nextjs-seo-site`: `nextjs-site-architecture`, `seo-setup`, `seo-catalog-urls`, `seo-structured-data`, `seo-i18n`, `seo-audit`.

- **Главная текущая проблема:** страница товара сейчас рендерится только в браузере (Worker отдаёт `index.csr.html`), поэтому поисковик видит пустой шаблон. Next.js отдаёт готовый HTML.
- **Метаданные:** уникальные title и description, canonical, Open Graph. Версии `uk`/`ru` связаны через hreflang и x-default.
- **`sitemap.ts`** с разбиением по разделам, **`robots.ts`**, `noindex` на непродакшн-доменах.
- **JSON-LD:** Organization, WebSite, BreadcrumbList, Product + Offer (цена и наличие), ItemList для списков.
- **Фасетные URL:** фильтр с одним значением (например, одно покрытие) можно индексировать как посадочную страницу. Комбинации фильтров, сортировка и вид «таблица» ставят canonical на категорию.
- **Текущие URL сохраняем:** `/uk|ru/catalog/{slug}/products`, `/uk|ru/catalog/product/{slug}`. 301-редирект только там, где адрес меняется.
- **Контент:** уникальные описания категорий и товаров. Эту часть заполняет владелец, а не код.
- Простой дизайн помогает SEO: меньше тяжёлых украшений и выше скорость (Core Web Vitals), весь важный текст на странице — именно текст, больше внутренних ссылок.

## Этапы

Один PR на этап, слияние только по согласию владельца, после реализации — аудит структуры кода.

1. SDD (`nextjs` + SEO-дизайн) и дизайн-система.
2. Каркас: шапка, подвал, темы, языки, API-клиент.
3. Каталог: фильтры, таблица, фасетные URL.
4. Страница товара с JSON-LD.
5. Корзина и быстрый заказ.
6. Статьи, страницы компании, регионы, сотрудничество.
7. Sitemap, robots, редиректы, SEO-аудит.
8. Переключение домена и аудит структуры кода.

## Зависимости и открытые вопросы

- Переезд API на `api.classkedr.com.ua` (KedrStore #138, kedr-web #12).
- Оптовые цены в кабинете требуют B2B-кабинета с персональными ценами (идея 9 в [feature-ideas.md](../feature-ideas.md)).
- Фото товаров на однородном фоне — от их качества сильно зависит вид минималистичной витрины.
- Оставлять ли двери в каталоге: в текущем меню они есть.
- Возможная доработка «добавить характер»: смелее использовать зелёный, блок новинок и акций.
