# Идеи функционала Kedr

**Статус:** заметки, не принятые решения. Собраны 2026-10-26 по аудиту kedr-web и KedrStore. Перед реализацией идею нужно оформить как SDD по [правилам поставки](../standards/shared/delivery-rules.md).

Усилия грубые: **S** около 1–2 дней, **M** около недели, **L** две недели и больше.

## 1. Находки аудита

- **Админские API открыты без входа.** Контроллеры клиентов, заказов, рабочего места заказов, товаров и категорий в KedrStore помечены `AllowAnonymous`. Роли Admin и Manager есть, но не применяются. В спецификациях это записано как временное решение.
- **Заказы с сайта теряются.** Быстрый заказ (`POST /api/orders`) создаёт Excel и шлёт его в Telegram, но нигде не сохраняется и не виден в админке.
- **Демо-данные.** Обзор в админке и личный кабинет на витрине показывают статичные цифры.
- **Бэкенд умеет больше, чем UI.** Повтор отправки заказа в 1С (`POST /api/admin/orders/{id}/sync/retry`) не вызывается из интерфейса.
- **Мобильное приложение.** Главный экран пустой, вкладка «Профиль» открывает товары без фото.
- **Витрина.** Готовые главная страница и блок «В наличии» не подключены. Статьи хранятся прямо в коде (`article-list.data.ts`).

## 4. Новые функции для сайта, оптовиков и склада

Отложены: часть из них требует данных, которых в 1С сейчас нет (размеры, штрихкоды).

- **Подбор замка и механизма по размерам врезки** плюс фото старого замка. Под специализацию ClassKedr «замена фурнитуры без замены двери». Нужны размеры товаров (см. A2). M–L.
- **Доставка Новой Почтой и онлайн-оплата** (LiqPay или monobank), ТТН и трекинг из админки. M–L.
- **Комплект к двери** на витрине со скидкой. M.
- **«Сообщить о поступлении»** и учёт спроса на отсутствующие товары. S–M.
- **Заявка на замер и установку** с календарём мастеров, если компания оказывает эту услугу. M–L.
- **Избранное, сравнение, отзывы с фото.** S–M.
- **Telegram-бот для оптовиков:** остаток, личная цена, заказ, статус. M.
- **Персональный прайс-лист** по расписанию. S–M.
- **Сканер штрихкодов** в мобильном приложении. Нужны штрихкоды в 1С. S–M.
- **Возвраты и гарантия** с фото и статусами. M.
- **AI:** поиск товара по фото, консультант на сайте. M–L.
